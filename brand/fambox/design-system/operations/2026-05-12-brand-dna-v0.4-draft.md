# Brand DNA v0.4 反映 draft

## 背景

Brand DNA v0.3（現行）は「**視覚言語 = Editorial × Lab + Drive 主導 + Bento 構図**」を中心に体系化済。今回の 19 セッションで「**実装規律 = Marc 流 4 層スタック + Phase 戦略 + SKILL 体系**」を確立したため、v0.4 で「**実装規律**」を DNA の第 2 軸として追加することを提案。

## v0.4 で追加する 4 セクション（Brand DNA に挿入候補）

### Section A: 実装規律の Marc 流 4 層スタック

DNA は「視覚」だけでなく「**それを再現する手順**」も含めて初めて完成する。Marc-Antoine の Smart City Kit から学び、FAMBOX に翻訳した 4 層スタック:

| Layer | 役割 | FAMBOX 実装 |
|---|---|---|
| **L1 Transport** | 作業環境の規律 | git worktree + PR ベース + Build Log |
| **L2 Skill** | 再利用可能な手順 | `figma-component-from-spec` SKILL v0.6 (610 行) |
| **L3 Tokens** | 設計原子 | Figma Variables (colors / typography / spacing) + Effect Styles |
| **L4 Definitions** | プロジェクト固有指示 | `<project>/CLAUDE.md` + spec md (components/*.md) |
| **L5 Audit-first** | プロトコル | 何かを作る前に必ず既存資産を全件確認 |

### Section B: Phase 戦略（実装の段階構造）

DNA は「完成形を一気に作る」のではなく、**段階的に進化させる**。Marc 流から確立した 4 Phase:

```
Phase 1: 新規生成（代表 variant のみで型作り）
   ↓
Phase 2: variant property 拡張（rename → clone → grid 配置）
   ├─ 事前 audit: 既存サイズ統一 / auto-layout 変動耐性確認
   └─ 1D / 2D matrix 配置パターン
   ↓
Phase 3: Component 間参照確立（双方向参照で DRY 実現）
   ├─ 事前 audit: target placeholder × source variant size cross-check
   ├─ Pattern A: placeholder → instance（新規 instance 作成）
   └─ Pattern B: instance → instance swap（in-place 切替）
   ↓
Phase 4: コンテンツ最適化（auto-layout 補修）
   └─ 補修ヘルパー 3 種: VERTICAL / HORIZONTAL / NONE layout
```

「**Phase 戦略は線形でなく入れ子・条件連動**」（学び 44）。Component の状態に応じて Phase を行き来する。

### Section C: Spec md ↔ Figma Component Set ↔ Build Log の三位一体

DNA の永続化には「**3 つのドキュメント往復**」が必須:

- **Spec md** (`components/*.md`): 設計の一次資料、CSS / Liquid / Do-Don't を厳密に記述
- **Figma Component Set**: 視覚的実装、Variables / Effect Styles で Spec を再現
- **Build Log** (`operations/figma-build-log.md`): セッションごとの成果 / 発生問題 / 学びを蓄積

**この 3 つが循環することで「DNA は文書から実装へ、実装から学びへ、学びから文書へ」と進化する**（学び 30, 36, 43）。

### Section D: Audit-first を DNA の Brand Principle に格上げ

既存 Brand Principle は「Editorial」「Lab」「Drive」「Co-driven」「Integrity」の 5 軸。v0.4 で **6 軸目「Disciplined（規律ある）」** を追加候補:

> **Disciplined（規律ある）**: 何かを作る前に必ず既存資産を確認する。Audit-first protocol は DNA の実装規律として、視覚言語と同等の重要度を持つ。

これにより、Brand DNA は「**視覚言語 5 軸 + 実装規律 1 軸 = 6 軸**」として完結する。
