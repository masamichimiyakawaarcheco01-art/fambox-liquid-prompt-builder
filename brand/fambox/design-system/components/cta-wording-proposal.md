# CTA Wording Proposal — Brand DNA 起点の文言候補

**原則**:「CTAの役割」× 「Brand DNA原則」の2軸で文言を選定。
- CTAの役割 = 何を促すか（情報閲覧 / 資料入手 / 対話開始 / 申込み）
- Brand DNA = Integrity（誠実）/ Drive（推進）/ Together（共創）/ Anti（押し付けない）

---

## 1. DNA 由来の文言ガイドライン

### ✅ Do（DNA に即した語感）
- 動詞スタート（「動かす」「続ける」「挑む」）
- 能動性を自然に示す（押しつけでない）
- 数字や根拠を添えて誠実に（例: 「3分でわかる診断」）
- 「任せる」「相談する」「共に」等、Co-driven × Integrity の語感

### ✕ Don't（DNA違反＝Anti発動）
- 「今すぐ」「限定」「お得」「無料」だけの煽り — Anti "媚びた広告" 違反
- 「必ず勝てる」「保証」— Integrity 違反（確率思想に反する）
- 「お試し」— 関係性が薄い（共創者スタンスと矛盾）
- 「体験する」— 意図不明、B2Bで距離が遠い

## 2. CTAの役割別 文言候補

### 役割A: 情報閲覧（Informational）
閲覧を促すだけの低ハードル CTA。

| 文言 | 語感 | DNA整合度 |
|---|---|---|
| **プランを見る** | シンプル・誠実 | ★★★ |
| 料金を確認する | 具体的 | ★★★ |
| 詳細を見る | 定番 | ★★☆ |
| もっと見る | 曖昧 | ★☆☆ |
| 事例を見る | Case Study へ | ★★★ |

**推奨**: 「**プランを見る**」「**事例を見る**」「**料金を確認する**」

### 役割B: 資料入手（Document / Material Download）
リード獲得で最重要。資料請求や診断スタート。

| 文言 | 語感 | DNA整合度 |
|---|---|---|
| **資料を見る** | シンプル・圧がない | ★★★ |
| **資料をダウンロード** | 具体的 | ★★★ |
| 資料をリクエスト | やや堅い | ★★☆ |
| 資料を請求する | 古い・B2B堅い | ★☆☆ |
| **診断を始める** | 能動的・共創的 | ★★★ |
| **3分でわかる診断** | 数字で誠実・具体 | ★★★ |

**推奨**: 「**資料を見る**」「**診断を始める**」「**3分でわかる診断**」

### 役割C: 対話開始（Consultation）
問合せ・相談へ誘導する重要 CTA。**DNAで最も重視される文脈**。

#### 🎯 2026-04-20 宮川さんFB反映：**悩むユーザの背中をそっと押す**CTAへ再設計

ベースライン「まずは話を聞いてみる」のニュアンスを軸に、**低コミット前置き × 〜してみる試行形** の組み合わせで再構築。

#### CTA の「背中押し」3要素

| 要素 | 機能 | 採用語句 |
|---|---|---|
| **① 低コミット前置き** | 「まだ決めなくていい」と伝える | **まず** / **まずは** / **一度** / **気軽に** / **ちょっと** / **とりあえず** |
| **② 試行形（〜してみる）** | 「やってみて駄目でも戻れる」 | **〜してみる** / **〜から始める** |
| **③ 動詞選定** | 心理的ハードルを動詞で決める | **聞く**（受動的）＜ **相談する**（対話的）＜ **申し込む**（行動的）|

⚠️ 宮川さん指摘: "話を聞く" / "栄養戦略を相談する" が「ピンとこない」理由 = **①低コミット前置き、②試行形** が欠落しているため、"決断を迫られる" CTA に見えるから。

#### 再設計候補（強さ順）

##### 🟢 Tier A — 最も背中押し強い（候補本命）

| # | 文言 | ①前置き | ②試行 | ③動詞 | 文字数 | DNA整合度 |
|---|---|---|---|---|---|---|
| A1 | **まずは話を聞いてみる** | まずは | ✓ | 聞く | 10字 | ★★★（ベース案） |
| A2 | **一度、話を聞いてみる** | 一度 | ✓ | 聞く | 10字 | ★★★ |
| A3 | **気軽に話を聞いてみる** | 気軽に | ✓ | 聞く | 10字 | ★★★ |
| A4 | **ちょっと話を聞いてみる** | ちょっと | ✓ | 聞く | 11字 | ★★☆ |
| A5 | **まずは相談してみる** | まずは | ✓ | 相談 | 9字 | ★★★ |

##### 🟡 Tier B — 落ち着いた背中押し

| # | 文言 | 意図 |
|---|---|---|
| B1 | **相談から始めてみる** | 「始める」で行動の階段を見せる |
| B2 | **まず知ってみる** | 「聞く」より距離感あり・情報受動 |
| B3 | **一度、相談してみる** | 堅めのB2B文脈 |

##### 🔴 Tier C — 参考（採用回避）

| # | 文言 | 回避理由 |
|---|---|---|
| C1 | 話を聞く | 前置き・試行形ゼロ → 決断迫り感 |
| C2 | 栄養戦略を相談する | 固い・9字で重い |
| C3 | 無料で相談する | 「無料」で媚び気味・Anti違反 |
| C4 | 今すぐ相談 | 「今すぐ」煽り・Anti違反 |

#### 🏆 推奨Final 3案（A/B/C選択用）

| 案 | 文言 | 使いどころ | 性格 |
|---|---|---|---|
| **A** | **まずは話を聞いてみる** | TOP Hero / 全ページ Footer CTA | ◎ バランス型・宮川さん好み基調 |
| **B** | **一度、話を聞いてみる** | B2B資料LP / プラン詳細下 | 少し知的・B2B好みのトーン |
| **C** | **気軽に話を聞いてみる** | Blog下 / コンテンツLP | 柔らか・ジュニア層LPにも馴染む |

#### 使い分け推奨（全部採用する場合）

- **Primary CTA（全画面の主役）**: 案A「まずは話を聞いてみる」
- **B2B 提案書・営業資料内**: 案B「一度、話を聞いてみる」
- **コンテンツ側（Blog／食事診断結果）**: 案C「気軽に話を聞いてみる」

#### 補足: ニュアンス分解メモ

- **「まず」「まずは」**: "先にこれだけ済ませれば良い" の含意。B2B 意思決定者に有効
- **「〜してみる」**: 試行動詞で commitment を実質ゼロ化
- **「話を聞く」**: 受動的＝一方的説明を受ける姿勢。会社側が説明責任を持つ含み → **Integrity（誠実）** と整合
- **「相談する」**: 双方向＝ user も発話する姿勢。**Co-driven（共創）** と整合
- **「聞いてみる」** >「相談してみる」の安心感理由: 相談は "自分から喋る" プレッシャー、聞くは "情報受動" で楽

### 役割D: 申込み・契約（Purchase / Commit）
最終 CTA。最もハードルが高い行為。

| 文言 | 語感 | DNA整合度 |
|---|---|---|
| **定期便を始める** | シンプル・能動 | ★★★ |
| **このプランで始める** | 選択後の誠実な一押し | ★★★ |
| 申込む | 最終行動が明快 | ★★★ |
| 今すぐ始める | 煽り気味 | ★★☆ |
| 申し込む・契約する | 堅い | ★★☆ |

**推奨**: 「**定期便を始める**」「**このプランで始める**」

### 役割E: キャンセル・戻る（Negative）
戻る・キャンセル系。Ghost ボタンで使う。

| 文言 | DNA整合度 |
|---|---|
| キャンセル | ★★★ |
| 前に戻る | ★★★ |
| やめる | ★★☆（シンプルすぎ）|
| 閉じる | ★★★ |

## 4. ボタン内文字数のガイドライン（背中押しCTAに合わせて更新）

| ボタンサイズ | 日本語文字数 | 英字文字数 | 主な用途 |
|---|---|---|---|
| SM | 3-5文字 | 6-10文字 | Card内 / フィルタ |
| MD（標準）| **4-10文字** | 8-16文字 | 標準UI・フォーム・Footer |
| LG | 6-12文字 | 10-20文字 | **Hero / 主役CTA** |

### 文字数更新の根拠
- 背中押しCTAは **「まずは〜してみる」形式で 10字前後** が避けられない
- SM 3-5字は無理。**Hero / 主要 CTA は必ず LG サイズ**（最小 MD でパディング確保）
- MD の上限を 8→10字 に拡張

### 推奨サイズ × 文言

| サイズ | 例 | 文字数 |
|---|---|---|
| LG | **話を聞いてみる**（Hero Primary）| 7字 |
| LG | **このプランで始めてみる** | 11字 |
| MD | **話を聞いてみる**（標準 Primary） | 7字 |
| MD | **資料を見てみる** | 7字 |
| MD | **診断を始めてみる** | 8字 |
| MD | **プランを見る** | 6字 |
| SM | **事例を見る** | 5字 |

## 5. Hero の主CTA ✅ 2026-04-20 確定

### 確定: **「話を聞いてみる」**（7字）

宮川さん決定: 「〜してみる」試行形を保持、前置き（まず/一度/気軽に）は不要と判断。7字で十分な背中押し効果。

### 確定運用ルール
- **Primary CTA（全画面）**: **「話を聞いてみる」**
- **ボタン文字数ガイドライン**: 10文字以内 OK（MD上限を 8→10 に拡大 ✅ 確定）
- **サブCTA（Secondary / Ghost）**: 役割B（資料）/ 役割A（情報閲覧）から選択

### 全画面統一のメリット
- 文言の揺れを排除 → ブランド想起性が上がる
- 運用・翻訳・A/B比較が明快
- Brand DNA の Integrity（誠実・シンプル）と整合
