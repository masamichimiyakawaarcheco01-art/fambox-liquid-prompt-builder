# FAM BOX Brand DNA — 意思決定ログ（ADR集約版）

重要な意思決定を時系列で記録。後から「なぜその選択？」を追うためのもの。新しい決定は新しいADR番号で追記。

## ADR-001: Vision は FAM から継承する（2026-04-20）
- **決定**: 「すべてのアスリートに、スポーツ栄養アドバイザーを」を FAMBOX もそのまま採用
- **選択肢**: a) そのまま継承 / b) B2B寄せ「すべてのチームに〜」
- **採用**: a
- **理由**: FAMマスターブランドと整合性を保ち、対象範囲を狭めない。B2B特化はL2 Strategic Coreで差別化する

## ADR-002: Brand Concept「Your Step. Our Drive.」を FAM×FAMBOX 同一運用（2026-04-20）
- **決定**: 「Your Step. Our Drive. — あなたの挑戦が、スポーツの未来を動かす」を FAMBOX も継承
- **選択肢**: a) 継承 / b) サブコピー追加 / c) 完全差分
- **採用**: a
- **理由**: ブランド体系を単純化。B2B文脈の訴求はタグライン（L1-6）で補う

## ADR-003: Anti（反対概念）をブランド核 L1-0 に格上げ（2026-04-20）
- **決定**: インタビュー3名（大前／深澤／三宅）共通項として「避けるもの」を L1 レベルの独立要素として定義
- **理由**: Anti-list は全記事・インタビューで最も一貫していた要素。ブランドの輪郭は "何でないか" で定まる
- **影響範囲**: L3 禁句・L4-15 写真NG・L7 運用ガイドのDon'ts すべての基準となる

## ADR-004: Core Values に Integrity（6番目）を追加（2026-04-20）
- **決定**: Drive / Science / Together / Continuity / Personalized に Integrity を追加
- **Integrity の定義**: 誠実・実直・本物志向。結果を言い切らず、取り組みの質と継続で「可能性の確率」を上げる
- **理由**: インタビュー（大前さん）で最も繰り返された「確率を上げる」「アシックス的本質主義」を Values として内在化

## ADR-005: 戦う市場を「栄養ソリューション市場」として独自定義（2026-04-20）
- **決定**: 宅食／ミールキット市場（シンプルミール／nosh／筋肉食堂）から市場そのものを分離
- **再定義**: 「食事・サプリ・水分補給・摂取タイミング・アカデミー」を束ねた"栄養戦略を設計・運用するチーム"
- **理由**: 深澤さん指摘「宅食はあくまで手段のひとつ」。競合比較の土俵を変える PODの根幹
- **影響**: L2-1（市場）／L2-4（機能便益）／L2-6（POD）すべてを再構成

## ADR-006: ターゲット選定基準は「態度（本気度）」（2026-04-20）
- **決定**: 競技レベル（プロ／アマ／学生／ジュニア）を対象選定の主軸にしない
- **主軸**: 「栄養に本気で向き合う意志のある層」のみ
- **理由**: 大前さん発言「本気で栄養に向き合う人だけを支援」。興味がないなら対象外という明確な境界

## ADR-007: ブランドキャラクターを二層構造で定義（2026-04-20）
- **決定**: 単一人格ではなく「基準人格（Primary・正）+ 適応レイヤ」の二層構造
- **Primary**: 大前さん型＝ベタベタしない・対等・冷静と情熱の間
- **適応レイヤ**: トップ向けは Primary のまま／本気×リテラシー未熟層には誠実に翻訳する責任
- **理由**: "寄り添い過ぎ"と"ツンケン"の両極を避けた「本気度に応じた適切な近さ」の言語化
- **次論点**: 大前さん/村野さん の個別差分（お母さん型？）を v0.7 で議論

## ADR-008: 関係性を「共創者（Equal Partner in Challenge）」として正式命名（2026-04-20）
- **決定**: 関係性の姿勢を「共創者（Equal Partner in Challenge）」という公式用語に統一
- **構成**: 対等＋伴走者＋Challenge（競技・栄養・成長の挑戦を内包）
- **理由**: 大前さん指摘「寄り添う＝自己満足化懸念」。代替語として「パートナーシップ」より明示的な「共創」を採用

## ADR-009: 色・タイポ・UI部品等をデザインシステム側に移管（2026-04-20）
- **決定**: ブランドDNAから以下11要素をデザインシステム（別ドキュメント）に移管
  - 色（Brand 5色/Semantic/Data）／タイポ／グリッド＋Bento／モーション／入力UI／ナビ／B2B資料規格／CTA（文言・形状）／アイコンセット／音・触覚
- **理由**: DNAは "WHY/WHAT"、DSは "HOW" の責任分離。ドキュメントの寿命・変更サイクルが異なるため

## ADR-010: ブランドリポジトリ構造を4層化（2026-04-20）
- **決定**: `brand/` 配下を `current.md / drafts/ / archive/ / decisions/ / references/` の4層に再構築
- **理由**: 「最新版どれ？」問題の解消／意思決定の追跡可能性／Claude の読み取り効率向上
- **ルール**: `current.md` は常に最新draftのコピー／確定時は `v{MAJOR}.{MINOR}.md` にも昇格

## ADR-011: L1-6 Messaging Pillar を 2 案に確定（2026-05-22 / v0.7）
- **決定**: FAM BOX 専用 Pillar として 2 案を採用 — Pillar 1「栄養で、可能性の確度を上げる」/ Pillar 2「支えるではなく、共に創る」（両方併用）
- **選択肢**: a) Pillar 1 のみ / b) Pillar 1 + Pillar 2 併用 / c) Pillar 1 + 別の案
- **採用**: b
- **理由**: L1-4 Integrity（誠実原則）と L3-5 共創者（Equal Partner）の 2 大価値観に直結。Pillar 1 = 「何を提供するか」、Pillar 2 = 「どう接するか」で役割が補完的
- **「確率」→「確度」の修正**: B2B 文脈で「確率」は冷たく誇張に近づく → 「確度」（確からしさ・精度）が Integrity 原則と自然に接続
- **Drop 案**: 「チームにスポーツ栄養を、選手に力を」/ 「目標は、食事から変えられる」/ 「チームを次のステージへ」/ 「結果は言い切らない。確率は上げられる。」
- **FAM 継承**: 「Fuel your next step.」「Carry You Further.」は FAM 単独運用接点で継続使用

## ADR-012: L2-1 サブセグメントを 3 層階層に再定義（2026-05-22 / v0.7）
- **決定**: 「a 第一優先 / b 第二優先 / c 第三優先」の 3 層階層として確定。差別化軸は a 層に集中
- **選択肢**: a) B2B 全般+トップアスリート / b) 部活動・学校市場 / c) プロ実業団専属代行
- **採用**: 単独選択ではなく 3 層階層に統合（a > b > c の優先順）
- **階層構成**:
  - **a 第一優先**: 監督・コーチ・実業団事務局・選手・**トップアスリート（法人契約しているプロ）** — 高単価・実績軸
  - **b 第二優先**: 普通のアスリート、大学・高校等の部活チームや顧問・マネージャー、クラブチーム — 中単価・普及
  - **c 第三優先**: 保護者・栄養士、スポーツ栄養士 — Influencer 層
- **a 層差別化軸**: 「実績や信頼 — トップのスポーツ栄養士・トップアスリートの関わり/監修」（L2-6 POD の中核）
- **理由**: 既存実績（トヨタ硬式野球部・テイ・エステック・森谷選手）が全て a 領域。b/c は段階的に拡張する第二・第三経路として位置づけ

## ADR-013: L2-2 ターゲット第一優先を「法人プロ起点」に確定（2026-05-22 / v0.7）
- **決定**: 第一優先 a 層 = Buyer + Economic Buyer + End User（法人契約しているプロのアスリート / トップアスリート）
- **選択肢**: a) Buyer・EB・アスリート起点 / b) Influencer 起点 / c) Champion 起点
- **採用**: a
- **理由**: B2B 定期便モデルで意思決定者への最短到達が CVR 3.0% 達成の前提。Champion（専属栄養士）は中規模以上のチームのみ存在で B2B フックとして弱い。Influencer は SNS/Blog で第二経路として並行運用
- **到達戦略**: 営業面談（事業開発：三宅・深澤・井上経由のリファラル）+ 法人LP 直接フォーム → 試食 + チーム別個別プラン提案 → 単月契約からの育成
- **影響**: KR2-1（4 画面 DNA 反映）の TOP / 法人 LP / 問合せページの主要メッセージは全て a 層に最適化

## ADR-014: L3-1 ブランドキャラクターを 1 人格固定に確定（2026-05-22 / v0.7）
- **決定**: v0.6.3 の二層構造（Primary + 適応レイヤ）を**廃止** → 大前さん型のみで一貫、温度調整なし
- **選択肢**: a) 1 人格固定（大前さん型） / b) 二層構造（v0.6.3 のまま） / c) 複数ペルソナ並列
- **採用**: a
- **理由**:
  - ブランド一貫性を最優先（運用ぶれリスクの根絶）
  - a 層（法人プロ・トップアスリート）への最適化を最優先
  - b 層（部活・クラブ）には大前さん型の語り口のままで届く層のみが対象 — 意図的に「本気勢のみが残る」運用
  - c 層（保護者・栄養士）には接点設計で対応（Blog/セミナー/アカデミー）— ただしキャラ自身は大前さん型のまま
- **影響**: 「ピヨピヨ層への寄り添い」は意図的に Anti として扱う。L3 全般を 1 人格固定方針で v0.8 / v1.0 で再整合
- **大前さん／村野さん個別差分の扱い**: 個別名は出さない。実在の栄養士は「FAM BOX の語り口を体現する個人」としてコンテンツ内で登場。監修クレジット表示は OK

## ADR-015: L4-14 ロゴ運用 — FAM BOX を独立ブランドとして確定（2026-05-22 / v0.7）
- **決定**: FAM = 母体組織 / **FAM BOX = アスリート向け総合栄養ソリューションという独立ブランド・事業**
- **選択肢**: a) 「FAM | FAMBOX」併記（親子明示） / b) FAM BOX 独立ロゴ / c) FAM ロゴ + 「BOX」修飾子
- **採用**: b
- **理由**: FAM はコーポレートブランド、FAM BOX は事業ブランドとして独立性を明示。サブブランド扱いだと B2B 営業文脈で FAM BOX 独自性が弱まる
- **表記の正式統一（新ルール）**:
  - DNA 文書 / ブランドコミュニケーション / ロゴ / 正式名: **「FAM BOX」**（スペース入り）
  - 技術的識別子（URL / Shopify handle / Liquid section name / CSS class）: 「FAMBOX」（既存・スペースなし）を維持
  - 共同表記（プレスリリース・会社紹介）: 「FAM / FAM BOX」or「株式会社FAM の FAM BOX 事業」
- **影響**: 全資産の一括置換コストを回避しつつ、ブランド表記の独立性を確保。今後の制作物（プレスリリース・営業資料・新規 LP コピー）は「FAM BOX」表記を使用
- **ロックアップ詳細**: ①〜⑩（クリアスペース・最小サイズ・カラーバリ・co-branding 等）は v0.8 以降で具体化

## ADR-017: L2-6 POD を 3 階層構造で確定 + サプリメント提供範囲外を確定（2026-05-22 / v0.7+）
- **決定 1（POD 構造）**: v0.6.3 で羅列されていた 8 項目を **3 階層構造** に再整理 — Tier 1 コア（真似できない・参入障壁が高い）/ Tier 2 強化（運用・仕組みで差をつける）/ Tier 3 文化的（態度・体験で差をつける）
- **Tier 1 コア POD（3 項目）**:
  - #1 トップのスポーツ栄養士・トップアスリートの関わり/監修（**a 層差別化軸の中核** / ADR-012 連動）
  - #2 「栄養ソリューション」市場での独自定義（ADR-005 連動）
  - #3 スポーツチーム単位（B2B）対応体制
- **競合比較表**: シンプルミール / マッスルデリ / GREEN SPOON / nosh / 筋肉食堂 vs FAM BOX を 8 軸で比較 → **8 軸中 7 軸で全競合と明確差別化**。残る「食事の品質」軸は POP（L2-7）で同等以上を担保
- **Messaging Pillar との連動を明示**: Pillar 1（確度）= Tier 1 #1 + Tier 3 #7、Pillar 2（共創）= Tier 3 #8
- **決定 2（サプリ除外）**: **サプリメントは FAM BOX の提供範囲外**（宮川さん明示確認 / 2026-05-22）
- **影響範囲**: L2-1 市場定義 / L2-4 機能便益 / L2-6 POD から「サプリ」を全削除 → FAM BOX は **食品ベースの総合栄養戦略**（食事＋水分補給＋タイミング＋アカデミー）に集中
- **理由**: FAM BOX のコアバリューは「食」ベースの栄養設計と監修。サプリメント供給は別業態（薬機法・物流・在庫管理）であり、PoD の集中力を維持するためスコープ外とする
- **副次決定（表記統一）**: 「確率」→「確度」を本DNA 全文に反映（ADR-011 と整合）

## ADR-018: L2-3 JTBD を Top 5 に絞り込み（2026-05-22 / v0.7+）
- **決定**: a 層（法人プロ・トップアスリート起点）に対応する優先 JTBD を **Top 5** に絞り込み
  1. 属人化からの脱却 — 選手の食事管理を栄養のプロに丸投げできる状態にしたい
  2. 遠征・合宿時の栄養品質を一定に保ちたい
  3. 怪我を減らしてシーズンを戦い抜きたい
  4. オン/オフシーズンに合わせて最高のパフォーマンスを発揮したい
  5. 何をいつどれぐらい食べるか — タイミング不明問題を解消したい
- **各 JTBD を POD Tier 1/2 と直結マッピング**（属人化脱却 → Tier 1 #1 監修 + Tier 2 #4 三位一体 など）
- **Drop**: データで成績を説明（→ KR4-2 将来）/ 保護者説明（→ c 層は L5 接点で対応）/ 食堂設備が貧しい（→ b 層 部活向け）/ 予算（→ 前提条件）/ 自身の食生活見直し（→ #4 統合）/ 栄養士 JTBD 3 項目（→ L2-4 機能便益 #8 アカデミーで対応）
- **理由**: a 層に絞ることで Messaging Pillar / POD / 機能便益との一貫性が確保される

## ADR-019: L2-4 機能便益 / L2-5 情緒便益 最終確定 + 水分補給スコープ外（2026-05-22 / v0.7+）
- **決定 1（L2-4 機能便益）**: JTBD Top 5（ADR-018）順に **8 項目** を再整理
  1. **FAM スポーツ栄養アドバイザー**（旧「スポーツ栄養士サポート」改称・FAM 母体組織の公式役職として位置づけ）
  2. チーム単位の一括管理・配送オペレーション
  3. 合宿・遠征に応じた栄養サポート
  4. スポーツ栄養学に基づいた根拠ある栄養設計（エビデンス同梱）
  5. 個別最適化された食事プランの配送
  6. 食事診断による選手タイプ別レコメンド
  7. 摂取タイミング設計（オン/オフ/試合前後）
  8. アカデミー／セミナー（栄養知識の内製化支援・Champion 層支援）
- **決定 2（水分補給戦略をスコープ外）**: ADR-017 のサプリメント除外に続き、**水分補給戦略も FAM BOX の提供範囲外** として確定。FAM BOX の中核価値「食（食事）ベース」に集中するため。ハイドレーションは別業態 or 提携先で対応想定
- **影響範囲**: L2-1 市場定義 / L2-4 機能便益 / L2-6 POD Tier 1 #2 + Tier 2 #6 / 競合比較表「提供範囲」から「水分補給」を全削除 → 提供範囲は **食事 + 摂取タイミング + アカデミー の 3 本柱**
- **「FAM スポーツ栄養アドバイザー」改称の意義**: 競合の「管理栄養士監修」と明確に分離。FAM 母体組織の専属アドバイザーが直接関与する体制を実体化（POD Tier 1 #1 / a 層差別化軸と直結）
- **決定 3（L2-5 情緒便益）**: 1 人格固定方針（ADR-014）との整合で 4 ターゲット別に再整理（Buyer / End User / Champion / 共通）。**c 層保護者の直接便益訴求を Drop**（L5 接点設計で対応）。Buyer に「丸投げできる安心」を統合

## ADR-020: L2-7 POP 最終確定 — 配送品質×開封体験×アフターケアを整備優先領域に明示（2026-05-22 / v0.7+）
- **決定**: POP を 5 項目に整理。POD 競合比較表で唯一差別化していない「食事の品質」軸を Top に明文化（POP #1）+ 配送品質 × 開封体験 × アフターケア を整備優先領域として明示（POP #2）
- **POP #2 整備優先領域 5 項目**:
  - 2-1 時間指定配送（チーム練習・試合スケジュールに合わせた柔軟な日時指定）
  - 2-2 配送ステータスの連絡（出荷・配送中・到着の能動的連絡 / メール / LINE / Slack 連携）
  - 2-3 梱包のデザイン（FAM BOX ブランド世界観 / Editorial × Lab × アシックス的本質主義）
  - 2-4 開封時の体験性（「届いた瞬間に確度を実感する」開封体験設計 / 同梱物の順序・触感・読み物）
  - 2-5 アフターケア（開封後のチラシ・小冊子・QR 導線で「次の一手」を提示する CX 設計）
- **現状認識**: POP #2 領域は業界標準と比較してまだ未熟（宮川さん明示確認 / 2026-05-22）。FAM BOX が POD で築いた「監修×B2B×総合戦略」の差別化を活かすには、この POP 領域の整備が最優先課題
- **OKR 接続**: KR2-1（4 画面 DNA 反映 v1）と KR2-2（食事診断ローンチ）に直接接続。v1.0（6/30）以降の Phase 2 として実装ロードマップに組み込む
- **POP の役割明示**: 競合に対して POP #1（食事品質）+ POP #2（配送 × 開封 × CX）を同等以上に担保しつつ、POD で「監修体制 × B2B 体制 × 食事＋タイミング＋アカデミー」の総合戦略で差別化する 2 段構造

## ADR-021: L3-2 Tone of Voice / L3-3 推奨語彙 最終確定（2026-05-22 / v0.7+）
- **決定 1（L3-2 Tone of Voice）**: v0.6.3 ベースの 7 項目に 2 項目追加
  - 追加 #8: 「結果は言い切らず、確度を表す」（Pillar 1 / Integrity 整合）
