# L1 — Brand Core（ブランド核）

**変更サイクル**: 原則不変

## L1-0. Anti（反対概念・FAMBOXが徹底して避けるもの）★ v0.6.3 新規

**位置づけ**: ブランドの輪郭は"何であるか"と同じくらい"何でないか"で定まる。インタビュー3名（大前／深澤／三宅）で最も一貫していた項目のため、**ブランド核に格上げ**。

**徹底して避けるもの（Anti-list）**:
- 表面的／派手／"映え"重視／盛り
- エセ高級／媚びた広告／数字優先／浅い関係
- ブランド借り（有名選手起用のみの広告）／ギラついた広告マン
- 上から目線／机上の空論
- 安売り／キラキラ系ブランディング
- 可愛いイラスト／漫画／過度な演出
- インフルエンサー前面起用／スタジオ過剰演出
- "お客様対応"化／寄り添いすぎ／敷居を下げすぎる表現
- 「必ず勝てる」「効果を保証」等の過大表現

**Status**: ✅（インタビュー3名の共通項として確定）

## L1-1. Purpose（存在意義）
**現状**: スポーツ栄養でアスリートのパフォーマンスと社会のwellbeingに貢献する
**FAMBOX適用**: FAMミッションをそのまま継承
**Status**: ✅

## L1-2. Vision（目指す世界）
**確定**: すべてのアスリートに、スポーツ栄養アドバイザーを（**FAM継承**）
**Status**: ✅

## L1-3. Brand Concept（一言の約束）
**確定**: Your Step. Our Drive. — あなたの挑戦が、スポーツの未来を動かす（**FAM継承・FAM x FAMBOX 同一コンセプト運用**）
**Status**: ✅

## L1-4. Core Values（価値観6つ）
**確定（v0.6.3 で Integrity 追加）**:
1. **Drive** — 推進力で前へ押し出す
2. **Science** — アスリート個人のコンテクスト（個人の性格、身体の特徴、個人の目標、競技シーンにおける時間軸、今の心理状態、過去1か月の運動量、現在の食習慣）に応じたスポーツ栄養学に基づく根拠ある判断
3. **Together** — 対等な対話、FAMBOXとアスリートは共に尊重し合う
4. **Continuity** — 日々の積み重ねを尊ぶ
5. **Personalized** — 一人ひとりに向き合う
6. **Integrity** ★NEW — 誠実・実直・本物志向。**結果は言い切らず、取り組みの質と継続で「可能性の確度」を上げる**。アシックス的本質主義＝派手さよりも実用と成果で選ばれる立ち位置

**Status**: ✅（6項目確定）

## L1-5. 社会的価値観（Society）
**確定ドラフト（宮川添削反映）**:
- スポーツ栄養の民主化（プロだけでなく部活動・社会人チーム・法人・実業団・ジュニアにも）
- アスリート寿命の延伸（怪我予防・コンディション維持）
- チームの知的資本としての「食・栄養」の再定義

**Status**: 🔶（v0.7で最終表現確定）

## L1-6. Messaging Pillar ★ v0.7 確定（ADR-011）

**FAM継承（維持・FAM 単独運用接点で継続使用）**:
- Fuel your next step. — 次の一歩に、力を
- Carry You Further. — あなたを、次のステージへ

**FAM BOX 専用 Pillar（v0.7 で 2 案確定 / 両方併用）**:

| # | コピー | 結びつく価値観 | 主たる用途 |
|---|---|---|---|
| **Pillar 1** ★ | **「栄養で、可能性の確度を上げる」** | L1-4 Integrity（★誠実原則・大前さん談） | 営業資料表紙 / 法人LP メインコピー / 問合せ返信冒頭 / Blog タイトル直下 |
| **Pillar 2** ★ | **「支えるではなく、共に創る」** | L3-5 共創者（Equal Partner in Challenge） | 関係性の説明 / 商談導入 / About / 採用 / インタビュー記事 |

**「確率」ではなく「確度」を採用した理由**:
- 「確率」= 数学的・統計的（0-1）→ B2B 文脈で冷たく、誇張に近づく
- 「確度」= 確からしさ・精度 → 誠実・柔らかく、Integrity 原則と自然に接続
- アスリート/監督に対して「言い切らないが、精度は上げられる」という FAM BOX の立ち位置を最も正確に表現

**併用ルール**:
- **Pillar 1** は商品・サービスの存在意義を語る場で主役（「何を提供するか」）
- **Pillar 2** は関係性・態度を語る場で主役（「どう接するか」）
- 同一接点で両方を並べることは可能（タグライン群として）

**v0.7 で Drop した案**（記録）:
- 「チームにスポーツ栄養を、選手に力を」→ 既存表現的・POD に弱い
- 「目標は、食事から変えられる」→ 機能訴求寄りで Integrity と接続弱
- 「チームを次のステージへ」→ Carry You Further と重複
- 「結果は言い切らない。確率は上げられる。」→ 直接表現が強すぎるので Pillar 1 のシンプル版を採用

**Status**: ✅（v0.7 確定）

# L2 — Strategic Core（戦略核）

**変更サイクル**: 3年で見直し。**FAMBOX独自に最優先言語化が必要な層**。

## L2-1. 戦う市場（Business Domain）★ v0.7 サブセグメント確定（ADR-012）

**確定方針**: **「栄養ソリューション市場」として独自定義**。食事単体を提供する宅食／ミールキット市場（シンプルミール／nosh／筋肉食堂／マッスルデリ等）とは **市場そのものを分離**。「食事・摂取タイミング・アカデミー」を束ねた **"栄養戦略を設計・運用するチーム"** として位置づける。

> ※ v0.7 / ADR-017 で「サプリメント」、v0.7+ADR-019 で「水分補給戦略」を提供範囲から正式除外（FAM BOX は **食品（食事）ベース** の栄養戦略 + 摂取タイミング + アカデミーの 3 本柱に集中）

> インタビュー根拠（深澤さん）: 「宅食が一番前に出てきちゃってるけど、あくまでもあれも手段の一つでしかない。栄養戦略が上位概念」

### サブセグメント — 3 層階層（v0.7 確定）

優先順位は a > b > c。リソース配分・コンテンツ訴求軸・営業フォーカスはすべてこの順序に従う。

| 階層 | 構成メンバー | 単価帯 | 差別化軸 | 主な接点 |
|---|---|---|---|---|
| **a 第一優先** ★★★ | 監督・コーチ・実業団事務局・選手・**トップアスリート（法人契約しているプロのアスリート）** | 高単価（月10万-30万円規模） | **実績や信頼（トップのスポーツ栄養士・トップアスリートの関わり/監修）** | 法人LP / 営業面談 / トップ選手取材記事 / プレスリリース |
| **b 第二優先** ★★ | 普通のアスリート、大学・高校等の部活チームや顧問・マネージャー、クラブチーム | 中単価（個人購買 or チーム単位の小口） | 普及・教育コンテンツ / 試食・診断導線 | 食事診断 / Blog / SNS / 部活向け資料 |
| **c 第三優先** ★ | 保護者・栄養士、スポーツ栄養士 | Influencer 層（購買者ではないが意思決定影響大） | 科学的納得性・専門家ネットワーク | アカデミー / セミナー / 栄養士向け Blog / 学会・カンファレンス |

### a 層差別化の核

> **「実績や信頼 — トップのスポーツ栄養士やトップのアスリートの関わり・監修」**

これは FAM BOX が **競合（シンプルミール／マッスルデリ／GREEN SPOON 等）と最も鋭く差別化できる軸**。v0.7 で公式 POD として固定（L2-6 に反映）。

### Drop 案（記録）

- 「部活動・学校スポーツ食育市場（ボリューム重視）」→ b 層として残すが第一優先ではない。単価が合わない（FAM BOX 商品仕様：月10万-30万円規模）
- 「プロ／実業団 専属栄養管理代行（単価重視・限定）」→ a 層に内包（独立サブセグとはしない）

**Status**: ✅（v0.7 確定 — 3 層階層 + a 層差別化軸）

## L2-2. ターゲット（WHO）階層 ★ v0.7 優先順確定（ADR-013）

**前提（v0.6.3 継承）**: ターゲットは **「態度（本気度）」** で選ぶ。競技レベル（プロ／アマ／学生／ジュニア）は無関係。栄養に本気で向き合う意志のある層のみが対象。興味がないなら対象外。

> インタビュー根拠（大前さん）: 「プロ/学生は問わない。本気で栄養に向き合う人だけを支援」

### 階層定義（B2B 意思決定フレーム）

- **Buyer**: 監督・コーチ・マネージャー（意思決定者）
- **Economic Buyer**: 学校/クラブ事務局・**法人実業団事務局**（予算承認）
- **Champion**: 専属栄養士（実務担当・推進者）
- **End User**: 選手本人 / **法人契約しているプロのアスリート**
- **Influencer**: 保護者・栄養士・スポーツ栄養士

### v0.7 確定優先順 — a 層 = 「法人プロ起点」

**第一優先（a）**: **Buyer + Economic Buyer + End User（法人契約しているプロのアスリート / トップアスリート）**

- 意思決定スピード重視（B2B 法人契約で 1 商談あたり ARR が大きい）
- KR4-1 CVR 3.0% 達成のため、意思決定者への最短到達を最重要視
- 既存実績（トヨタ自動車硬式野球部・テイ・エステック・森谷選手）はすべてこの層

**第二優先（b）**: **Buyer + End User（普通のアスリート・部活/クラブチームの顧問・マネージャー）**

- 中規模チーム単位での導入。試食・診断からの育成型
- 数では a 層より多いが、単価が低い

**第三優先（c）**: **Influencer（保護者・栄養士・スポーツ栄養士）**

- 直接の購買者ではないが、a/b 層への意思決定影響大
- アカデミー・セミナー・栄養士コミュニティで間接的に接触

### a 層への到達戦略

- **入口**: 営業面談（事業開発メンバー：三宅・深澤・井上経由のリファラル）+ 法人LP 直接フォーム
- **信頼形成**: トップアスリート取材記事（森谷選手等）+ トップ栄養士監修の可視化（大前さん・村野さん）
- **クロージング**: 試食 + チーム別個別プラン提案 + 単月契約からの育成

**Status**: ✅（v0.7 確定）

a 層（法人プロ・トップアスリート起点）に対応する優先 JTBD を **Top 5** に絞り込み。POD Tier 1 #1（トップ栄養士監修）と直結。

| **2** | **遠征・合宿時の栄養品質を一定に保ちたい** | 監督・コーチ・事務局 | Tier 1 #3（B2B 体制）|
| **3** | **怪我を減らしてシーズンを戦い抜きたい** | 監督・コーチ | Tier 2 #5（栄養設計ロジック）|

| **5** | **何をいつどれぐらい食べるか — タイミング不明問題を解消したい** | 選手・トップアスリート | Tier 2 #6（総合戦略の摂取タイミング）|

### Drop した JTBD（記録）

- データで食と成績の関係を説明したい → 将来 KR4-2 で対応
- 保護者に説明したい → c 層 Influencer 経由で間接対応
- 食堂設備が貧しくても → b 層 部活向け（a 層では非該当）
- 予算に合う → JTBD ではなく前提条件
- 自身の食生活見直し → #4 に統合
- 栄養士 JTBD（献立工数削減 / 再現性担保 / コンディションデータ）→ L2-4 機能便益 #9 アカデミー / Champion 層支援で対応

**Status**: ✅（v0.7+ADR-018 確定）

| **3** | 合宿・遠征に応じた栄養サポート | #2 |

### v0.7+ADR-019 で除外した項目（記録）

- **サプリメント戦略**（v0.7 / ADR-017）— 別業態（薬機法・物流・在庫管理）であり、PoD の集中力を維持するためスコープ外
- **水分補給戦略**（v0.7 / ADR-019）— FAM BOX の中核価値「食（食事）ベース」に集中するためスコープ外。ハイドレーションは別業態 or 提携先で対応想定

> 位置づけ: 宅食は数ある手段のひとつ。FAM BOX は **食品（食事）ベースの栄養戦略** + **摂取タイミング設計** + **アカデミー** の 3 本柱で構成する"総合サポートチーム"。

### 「FAM スポーツ栄養アドバイザー」の位置づけ（v0.7 新規）

「スポーツ栄養士サポート」を改称。FAM 母体組織の **公式役職** として位置づけ、a 層差別化軸「トップ栄養士監修」を実体化する役割。

## L4-14. ロゴ運用（FAM × FAM BOX）★ v0.7 独立ブランド方針確定（ADR-015）

### v0.7 確定方針

**FAM = 組織・会社としての母体**（コーポレートブランド）
**FAM BOX = アスリート向け総合栄養ソリューションという独立ブランドであり事業**

### 表記の使い分けルール（v0.7 新規）

| 文脈 | 使用する表記 | 理由 |
|---|---|---|
| **DNA 文書 / ブランドコミュニケーション / ロゴ / 正式名** | **「FAM BOX」**（スペース入り） | 独立ブランドの明示・FAM 母体組織との切り離し |
| **技術的識別子（URL / Shopify handle / Liquid section name / CSS class）** | 「FAMBOX」（スペースなし） | 既存資産との互換性維持・置換コスト回避 |
| **共同表記（プレスリリース・会社紹介）** | 「FAM / FAM BOX」or「株式会社FAM の FAM BOX 事業」 | 母体組織と事業ブランドの関係性を明示する場面でのみ使用 |

### Drop した案（記録）

- a) 「FAM | FAMBOX」併記形式（親子関係明示）→ サブブランド扱いになり、FAM BOX の独立性が弱まる
- c) FAMロゴ＋「BOX」修飾子 → ブランドアイデンティティが分離されない
