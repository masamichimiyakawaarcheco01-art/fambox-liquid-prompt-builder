# シンプルミール（ヨシケイ夕食.net） — UI 観察コメント

- **TOP**: 旧来 EC 風 3 カラム。左ログインフォーム + バナー、中央サービス説明 + 料理写真、上部赤帯（重要なお知らせ）+ "夕食.net" ロゴ。赤 + 緑 + 黄の信号色、情報密度極高。
- **商品詳細**: シンプルミールカテゴリ。お弁当 3 種俯瞰を 3 列。緑帯「下期キャンペーン実施中」+ ハンバーグセット中央配置。商品名和文角ゴ、価格赤太字。
- **法人**: 汎用問合せフォーム。法人カテゴリ選択肢はあるが専用 LP 無し。左サイドのキャンペーンバナーで気が散る。

## FAMBOX との差分（5 観点）

1. **色**: 赤 + 緑 + 黄の信号色（FAMBOX と真逆）
2. **タイポ**: ジャンプ率弱、情報詰め
3. **写真スタイル**: 料理 + パッケージ + イラスト混在
4. **CTA shape**: 直角〜2px ボタン、別世代
5. **ヒーロー構造**: 3 カラム情報詰め

## FAMBOX への示唆（避けるべき UI パターン）

シンプルミールは **FAMBOX が避けるべき UI パターン**の代表例。

- 旧 EC スタイル（3 カラム情報詰め）
- 赤緑黄の信号色（Editorial と相反）
- ジャンプ率弱で「コピーで読ませる」ができない
- 法人 LP 不在で B2B 動線がない

FAMBOX は「Editorial × Quiet Drive」の真逆として明示的に位置づけ可能。
