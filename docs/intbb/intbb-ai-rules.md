# intBB AI デザインルール

- version: 0.1-draft（Layer 1 のみ確定 / Layer 2 は intBB フロント情報の受領待ち）
- last_updated: 2026-07-09
- owner: 宮川（ARCHECO）

> **このファイルの使い方**: intBB のミニアプリ UI を Claude 等の AI に作らせるとき、
> 最初にこのファイル全文を読み込ませて（またはプロンプトに貼って）から要件を伝える。
> AI はこのルールに従い、最後に §9 のチェックリストで自己点検してから出力すること。

---

## 1. 最優先ルール（AI はこれを絶対に守る）

1. **Layer 2 のトークン値（§2）を創作しない・変更しない。** 未確定の値は勝手に決めず、プレースホルダのまま人間に確認する。
2. 作る順番は必ず: **①平面構成 → ②余白 → ③整列 → ④タイポ → ⑤色・装飾**。色や装飾から作り始めない。
3. 寸法の決め打ち（「300px」等）でなく、**要素間の比率**でレイアウトを決める。
4. 生成後は §9 チェックリストを自分で実行し、違反があれば修正してから出力する。

## 2. intBB トークン（Layer 2 — ⏳ 未確定・フロント情報受領後に確定）

> 以下は intBB のフロントエンド実装・ブランド資産から抽出して確定する。
> **確定するまで、AI はこの節の値を推測で埋めてはならない。**

### 2-1. Color（役割は固定・値は未定）

| 役割 | 値 | 用途 |
|---|---|---|
| bg | ⏳ | 画面背景 |
| surface | ⏳ | カード / 面 |
| ink | ⏳ | 主テキスト |
| ink-muted | ⏳ | 副テキスト |
| accent | ⏳ | 強調 / CTA |
| line | ⏳ | 罫線 / 境界 |
| error | ⏳ | エラー |

グレースケール4段: Gray1 ⏳ / Gray2 ⏳ / Gray3 ⏳ / Gray4 ⏳

### 2-2. Type

- 日本語フォント: ⏳ ／ 英語フォント: ⏳
- 6段スケール: 飾り ⏳ / H1 ⏳ / H2 ⏳ / H3 ⏳ / Body ⏳ / Small ⏳
- ジャンプ率: ⏳（低=整然・堅実 / 高=躍動）
- 行間: ⏳

### 2-3. Layout / Components

- 余白 S/M/L（等比）: S ⏳ / M ⏳ / L ⏳（比率 1.5x or 2x）
- 角丸: ボタン ⏳ / カード ⏳ / 入力欄 ⏳
- シャドウ: ⏳
- PC最大幅: ⏳ / SPブレイクポイント: ⏳

## 3. 平面構成（Layer 1 — 確定）

- レイアウトは**単純な整数比**で分割する: 1:1 / 1:2 / 2:3 / 1:3 / Full のみ。中途半端な比率は禁止。
- 最も大きなコンテナの分割＝画面の構造設計。まず「どう割れば美しいか」、次に「どの比率で割るか」。
- 典型3分割: ナビ / ヘッダー / ボディ。

## 4. 余白（Layer 1 — 確定）

- 余白は**等比（1.5倍 or 2倍）で大中小**を定義する。**等差（10/20/30px 刻み）は禁止**。差はひと目で分かる大きさに。
- 割り当てポリシー（存在意義が同じ余白は同じ寸法）:
  - コンテナ ↔ 子要素の間 ＝ **大**
  - 兄弟要素どうしの間 ＝ **中**
  - 要素内のオブジェクト間 ＝ **小**
- 迷ったら「全部同じ余白1サイズ」でもよい（間延びするが破綻しない）。

## 5. 整列（Layer 1 — 確定）

- 要素をアラインして「**見えない線**」を通す。線の強さ＝コントラスト × サイズ × **連続性**。
- テキストはボックスのデフォルト余白を含むため、自動整列後に目視でアラインし直す。

## 6. タイポグラフィ（Layer 1 — 確定）

- 見出し/本文の**ジャンプ率**は §2-2 の指定に従う。
- **強調＝大きく・ハイコントラスト、補足＝小さく・ローコントラスト**。
- **行間はフォントサイズの1:1以上**をキープ。
- 6段スケール（§2-2）以外のサイズを場当たりで作らない。

## 7. 色の使い方（Layer 1 — 確定）

- 色は §2-1 の**役割どおり**に使う（ゾーニング）。役割を跨いだ流用禁止。
- 暗い背景は白文字、明るい背景は黒文字。
- **禁止**: FAM BOX / 他ブランドの色・フォントの流用。intBB のトークン以外を持ち込まない。

## 8. コンポーネント状態（Layer 1 — 確定）

- インタラクティブ要素は最低 **default / hover / disabled** の状態を設計する。
- フォーム系は **focus（枠=accent）/ 入力後 / error（赤枠＋エラーメッセージ）** も必須。
- ボタン2つのダイアログは「キャンセル＝弱 / 実行＝強」の強弱を付ける。
- 選択コントロール: 複数選択＝チェックボックス / 排他1択＝ラジオ / ON-OFF単体＝トグル。

## 9. 出力前チェックリスト（AI が自己点検する）

- [ ] レイアウト分割は整数比か
- [ ] 余白は等比の大中小か（等差になっていないか）
- [ ] 余白ポリシー（コンテナ-子=大 / 兄弟=中 / 要素内=小）に沿っているか
- [ ] 要素がアラインして見えない線が通っているか
- [ ] タイポは6段スケール内か／行間≥1:1か／強調と補足のコントラスト差があるか
- [ ] 色は §2-1 の役割どおりか／他ブランド色が混入していないか
- [ ] インタラクティブ要素に default / hover / disabled があるか
- [ ] §2 の未確定値（⏳）を勝手に埋めていないか
