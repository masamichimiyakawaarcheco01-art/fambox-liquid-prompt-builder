- **ネイビー × ゴールドのアイデンティティ**（BB ロゴ・見出し・送信ボタン）— そのまま規約トークンに昇格済み

## 1. 方向性 — 参考UI 6件に共通する3原則

参考UIはジャンルが違っても作り方が同じでした。intBB への翻訳は以下の3つに集約されます:

| # | 原則 | 参考UIでの現れ方 | intBB への適用 |
|---|---|---|---|
| 1 | **白ベース＋ヘアライン** | 背景はほぼ白。区切りは影や色帯でなく 1px の薄い線と余白 | ベージュ背景・色帯ヘッダーをやめ、白＋線に |
| 2 | **大きな数字・小さなラベル** | 数値 32〜40px の細身＋極小 muted ラベル。タイポが主役 | 使用量・今後のダッシュボード系に標準採用 |
| 3 | **アクセントは1色を少量** | ライム/グリーンをチップや強調カードだけに。ボタンは黒/濃色ピル | ネイビー=アクション、ゴールド=ごく少量の装飾に役割固定 |

**「箱を減らす」が抜け感の正体です。** 参考UIは枠付きボックスの数が極端に少なく、
リスト・ラベル・余白で構造を見せています。現行 intBB は小さな枠ボックスが多め（サイドバー
サブ項目・案内ボックス・警告帯×2）で、ここが印象差の8割です。

## 3. 画面別フィードバック（Before → After）

### A. 共通シェル【P1・効果最大】

1. **背景の白化**: `bg` を #FAFAFA に。ヘッダーの色帯を廃止して背景と一体化し、
   下辺 `border-bottom: 1px solid #ECECEC` のみで区切る。
2. **開発中警告の重複解消**: 現在ログイン画面とヘッダー右の2箇所に同文表示。
   ヘッダー右の1箇所だけに絞り、ベージュ帯 → **ゴーストチップ**
   （line 枠のピル＋ink-muted 文字＋⚠️は線画アイコン小）へ。恒常表示の警告は「静かに」が原則。
3. **右レール「成果物」**: 空のときはアイコンのみに折りたたみ（クリックで展開）。
   境界線は引かず余白で分離。

### B. サイドバー【P1】

4. **サブ項目の枠ボックス廃止**: deliverables / materials / meetings の各枠を外し、
   ゴーストリストへ。インデント＋hover 時のみ `background: #F4F4F5`、
   選択中は `background: rgba(31,58,95,.08)` ＋ primary 文字。箱が消えるだけで一気に抜けます。
5. 「ワークスペース」ラベルは 11px・uppercase・letter-spacing 0.08em・ink-muted に（参考UI共通の作法）。

### C. タブ【P1】

6. **絵文字アイコンの置換**: 🎨💬📮 → icons0.dev の線画アイコン（§5）16px に。
   UI クローム（タブ・ボタン・ナビ）に絵文字を使わない。
7. アクティブタブ: 現行の枠付きカード風 → **テキスト ink＋下線 2px primary**。
   非アクティブは ink-muted。枠を1つ減らす。

### D. チャット空状態【P1・体験改善の本丸】

8. 完全な空白 → 中央に **挨拶＋サジェストチップ 3〜4個**:
   「こんにちは、◯◯さん」＋「ナレッジを検索する」「議事録を取り込む」等のピルチップ
   （line 枠・クリックで入力欄へ挿入）。既存の「使えるスキル」チップ資産をそのまま転用可能。
   非デザイナー10名の初回体験がここで決まります。

### E. 入力バー【P2】

9. 入力欄をピル化（radius 999・line 枠・focus で primary 枠 1.5px）。
   添付📎は入力欄の左内側に統合。
10. 送信ボタン: navy 維持。ピル化 or 円形アイコンボタン（紙飛行機の線画）へ。

### F. ログイン画面【P2】

11. カード内の連続ボックス2つ（はじめての方へ＋開発中警告）を整理:
    「はじめての方へ」は**ボックスを外して本文テキスト2行**に、
    開発中警告はカード外（フッター上）の ink-muted 小テキストへ。
    カード内が「ロゴ＋タイトル＋説明＋ボタン＋2行」だけになり、参考UIの密度になります。
12. カード padding を1段階増やす（32→48px）。bg 白化に伴いカードは
    `border: 1px solid #ECECEC`＋ごく薄い shadow 1段で浮かせる。

### G. 数値表示パターン【P3・ダッシュボード移行の布石】

13. 「**大きな数字＋小さなラベル**」を標準パターン化:
    数値 32〜40px / weight 400〜500、単位は右肩に小さく、ラベルは 11px muted。
    使用量表示（0 / 100,000 トークン）から先行適用。
14. プログレスバー: 高さ 4px・ピル・トラック #EEEEEE・フィル primary。

## 5. アイコン運用 — icons0.dev を採用

- **サイト**: https://icons0.dev/ — 150+ コレクション / 20万+ アイコン、**MIT ライセンス（商用可）**。
  AI エージェントからの検索にも最適化されており、intBB の「AI に作らせる」運用と相性が良い。
- **導入方法**: `npx shadcn@latest add @icons0/<collection>/<name>`（React）または SVG コピー。
- **運用ルール（規約に反映済み）**:
  1. コレクションは**1つに固定**して混在させない（推奨: 線画系。渡辺さんの実装スタックに合わせて確定）
  2. サイズは 16 / 20 / 24 の3段、線幅 1.5px 相当で統一
  3. UI クロームに絵文字を使わない（チャット本文内は自由）
