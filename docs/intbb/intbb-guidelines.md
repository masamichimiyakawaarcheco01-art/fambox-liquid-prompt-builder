# intBB デザイン規約（人間向け）

- version: 0.2-draft（トークンはスクショからの暫定抽出。実装コード照合後に v0.1→正式化）
- last_updated: 2026-07-10
- owner: 宮川（ARCHECO）
- 対象: intBB のミニアプリを作る int メンバー（非デザイナー前提・約10名）

---

## 1. この規約の考え方 — 「緩め」です

**守ってほしいのは MUST の4つだけ。** あとは推奨（SHOULD）と自由（FREE）です。
既にみなさんが気合を入れて作ったミニアプリのデザインを壊す意図はありません。
統一するのは「intBB として並んだときの一体感」を作る最小限の部分だけです。

### MUST（4つだけ）

1. **色とフォントは intBB のトークン**（ネイビー×ゴールド×オフホワイト）を使う。他ブランドの色を持ち込まない
2. AI が未確定のトークン値を勝手に決めない
3. **押せるものには hover / disabled の状態**を付ける（フォームはエラー表示も）
4. **既存ミニアプリの移行時に、いきなりリデザインしない**（下記 §4）

### SHOULD（原則やる・理由があれば外してOK）

整数比レイアウト / 等比余白 / 要素の整列 / 控えめなジャンプ率。
外すときは PR やチャットで一言「ここは意図的に外した」と添えるだけでOK。

### FREE（完全に自由）

各ミニアプリの機能構成・アイデア・遊び心・イラスト・絵文字の使い方。個性は歓迎です。

## 2. ミニアプリ UI の作り方（3ステップ）

### Step 1: AI にルールを読ませる

Claude 等のセッション冒頭で `intbb-ai-rules.md` を読み込ませる（添付 or 全文貼り付け）。

### Step 2: 要件を伝える（プロンプトレシピ）

```
intbb-ai-rules.md に従って、intBB のミニアプリ画面を作ってください。

- アプリ名: <例: 経費精算ミニアプリ>
- この画面の目的: <ユーザーが何をする画面か1文で>
- 載せる要素: <箇条書き。例: タイトル / 入力フォーム3項目 / 送信ボタン / 履歴一覧>
- 画面の型: <中央1カード型 / 3ペイン型 / その他>
- 対象デバイス: <PC / SP / 両方>
```

**コツ: 見た目の指定（色・おしゃれに等）は書かない。** 見た目はルールが決めます。
ダッシュボード系を作るときは「誰が・何のために・どの頻度で見るか」も書くと精度が上がります。

### Step 3: 完成チェック（1分・5項目）

- [ ] **色**: intBB のネイビー×オフホワイトの雰囲気か（他サービスっぽい色が混ざっていないか）
- [ ] **見出し**: 何が一番大事な情報か、パッと見て分かるか
- [ ] **整列**: 要素の端が揃っているか
- [ ] **余白**: 詰まりすぎ・空きすぎの場所がないか
- [ ] **ボタン等**: 押せるものが押せそうに見えるか（hover / 無効状態があるか）

NG があれば AI に「チェックの◯番が NG。修正して」と返すだけ。自分で直そうとしなくてOK。

## 3. ダッシュボード・レポート系を作る人へ

AI-PJ 分科会の組織知として既に確定しているルールがあります（規約にも収録済み）:

- タブは「**ユーザー × 目的 × 更新頻度**」で分ける（経営/月次とマーケ/週次を混ぜない）
- 各タブの冒頭に「このタブのユーザーと目的」を1行書く
- 更新頻度が違う指標を並べるときは、頻度と最終更新日を明示する

## 4. 既存ミニアプリを intBB に移行する人へ

**そのまま持ってきてOKです。** 移行のためにリデザインは求めません。

- 余裕があれば: 色とフォントだけ intBB トークンに寄せる
- 今後その画面を改修する機会があれば: そのときに SHOULD ルールに寄せる
- 判断に迷ったら: そのまま移行して、規約の相談先（下記）へ一言

## 5. 困ったとき・ルールが合わないとき

- ルールどおりに作れない / ルールが実態に合わない → **⏳ 報告先（Slack チャンネル等）確定後に記載**
- 報告されたケースは「規約が悪い」前提で改訂候補にします（作った人を責めるためのルールではありません）

## 6. 規約の更新ルール

- バージョニング: v0.x（試行）→ v1.0（正式）。変更時は冒頭の version / last_updated を更新
- 承認者: ⏳ 確定後に記載
- レビュー周期: ⏳ ミニアプリの追加・移行ペースに合わせて設定
- 恒久ルール: 他ブランド（FAM BOX 等）の色・フォント・トーンを intBB に持ち込まない
