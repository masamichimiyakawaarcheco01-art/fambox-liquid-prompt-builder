## 🔁 MANIFEST 更新ルール

新規画像追加時：

1. Asset/ に置く（ファイル名は内容が分かるものに）
2. このファイルの該当カテゴリに追加（内容 + 推奨用途）
3. 「不足リスト」から削除（カバーした場合）
4. git commit

四半期に1回（1月・4月・7月・10月）、全体棚卸し：
- 使われていない画像のアーカイブ
- 新規撮影予定の追加
- カテゴリ再編
