# 梱包チラシ AI試作 vs 人力サンプル 比較・ブラッシュアップ整理 — 2026-06-02

> **4ステップループ ③ レビュー修正**の核心ステップ。宮川さん人力サンプル（完成に近い）と AI 試作（figma-bridge 構造組成）を Figma 上で並べて比較。
> 人力サンプル：`FAMBOX_C向け_表/裏_01`・`FAMBOX_B向け_表/裏_01`（Node 4:309 / 4:381 / 4:541 / 4:146）
> AI 試作：`01-C-front`〜`04-B-back`（Node 1:2 / 3:28 / 3:65 / 3:100）

最終更新：2026-06-02

---

## 結論（3行）

1. AI 試作は「**コピー + 情報構造 + 色トークンが入ったワイヤーフレーム**」。人力版は「**写真主導・高ジャンプ率・色ゾーニングの完成デザイン**」。
2. 最大の差は **① 写真の使い方 ② ジャンプ率（タイポの強弱）③ レイアウト（マルチカラム・非対称）**の3点。
3. つまり AI が出せたのは体感「3〜4割（ワイヤー）」で、人力の「6〜7割」には**デザインの craft 部分が丸ごと不足**。→ Flywheel の 7割/3割 境界の再定義が必要（後述）。

---

## 次元別の違い

### ① 写真の使い方（最大の差）

| | 人力サンプル | AI 試作 |
|---|---|---|
| 役割 | **写真が主役**。Hero ペア写真＋料理、カットアウト選手（B表）、喫食シーン、商品写真、調理写真、監修者の円形顔写真、スマホ実機モックアップ | グレーのプレースホルダ矩形のみ |
| 構図 | 写真ありきで余白・文字を配置（写真と文字が噛み合う） | 文字を積んだ後に写真“枠”を後付け |
| アクセント | 「Thank You!」手書きスクリプトを料理写真に重ねる | なし |

→ **写真は差し込むだけでなく、レイアウトを写真起点で組み直す**必要がある。

### ② ジャンプ率（タイポの強弱）

| | 人力サンプル | AI 試作 |
|---|---|---|
| Hero 見出し | 特大（「栄養を／最高の武器に」「ただの食事じゃない その1食」）= 画面の主役 | 24pt 程度。控えめで弱い |
| セクション見出し | 大きく太い（FAM BOXが生まれた理由 等） | 14–16pt、本文と差が小さい |
| 装飾フォント | 「Thank You!」「30% OFF」など筆記体・極太を混在 | なし（全て Inter 単調） |
| 全体 | **高ジャンプ率＝躍動感**（FAM の Propulsive 軸そのもの） | 低ジャンプ率＝平板・レポート的 |

→ Hero 40–56pt、セクション見出し 20–24pt に拡大。Poppins / Hiragino 適用。スクリプト系アクセント1書体を追加。

### ③ レイアウト・情報設計

| | 人力サンプル | AI 試作 |
|---|---|---|
| カラム | 2〜3 カラム、写真と文字を組み合わせた**エディトリアル** | 単一カラムで上から積むだけ |
| Hero 構造 | 分割（橙ブロック＋写真）／カットアウト写真コラージュ | 全幅の橙ベタ帯 |
| リズム | 非対称・視線誘導あり | 均質・抑揚なし |

### ④ 色の使い方

| | 人力サンプル | AI 試作 |
|---|---|---|
| ゾーニング | 橙＋**ディープブルー**＋ライトの**パネルで区画**（問い合わせ＝青ブロック等）、クーポンは橙/青ツートン | 橙帯＋白のみ。単調 |
| Deep Blue | セクション背景・問い合わせ帯で主役級に使用 | リンク文字だけ |

→ `--color-deep #0F2A5C` / `--color-sky` を**面で**使ってセクションを色分け。

### ⑤ 行間・余白

| | 人力サンプル | AI 試作 |
|---|---|---|
| 行間 | ゆったり（1.7–1.8） | 詰め気味 |
| 余白 | セクション間にしっかり余白、カードに padding | 全要素を詰め込み窮屈（A4 に収めるため圧縮した） |

→ 情報密度を下げて呼吸を作る。1枚に詰め込みすぎない。

### ⑥ ブランドアクセント / 部品

| 人力にあって AI に無いもの |
|---|
| FAM BOX ロゴロックアップ（橙アイコン＋ワードマーク） |
| 「Thank You!」手書きスクリプト |
| クーポンチケット形状（切り取り線・実コード `BB483HVWMNEZ`・実 QR） |
| スマホ実機モックアップ（購入フロー・サイト画面） |
| アイコン（メール／電話） |
| numbered step の角丸オレンジ四角 |
| サンクスリボン（「お買い上げいただきありがとうございます！」） |

### ⑦ ブランド名・コピー・IA の不一致

- **ブランド名は「FAM BOX」（スペース有）**。AI 試作は「FAMBOX」と表記 → 要修正（[[feedback_shopify_live_safe_push]] の FAMBOX→FAM BOX 統一と整合）。
- Hero コピーが違う：人力「栄養を、最高の武器に」/「ただの食事じゃない その1食」← v1 の「アスリート飯を、自宅の食卓に。」より強い。
- 実クーポン：30% OFF（C 裏）・初回 50% OFF（定期）・コード `BB483HVWMNEZ`。AI 試作はプレースホルダ。
- **B 向け裏面の IA が別物**：人力＝個人購入フロー＋栄養サポート（合宿・遠征／栄養セミナー）。AI＝アスリートの声＋導入4ステップ。→ どちらの構成を正とするか要すり合わせ。

## ブラッシュアップ方針（優先順）

### 最優先（第一印象を決める）
1. **写真主導に作り替え**：Hero はペア写真＋「Thank You!」スクリプト、B 表はカットアウト選手コラージュ。プレースホルダを実写真に置換＋構図を写真起点で再設計。
2. **ジャンプ率を上げる**：Hero 見出しを特大化、セクション見出しを拡大。Poppins（EN/Display）＋ Hiragino（JA）適用。
3. **ロゴ＆ブランド名**：「FAM BOX」（スペース有）＋ ロゴロックアップ（アイコン＋ワードマーク）に差し替え。

### 次点（構造の質）
4. **マルチカラム＋色ゾーニング**：2–3 カラム化。橙／ディープブルー／ライトのパネルでセクションを区画。
5. **行間・余白を緩める**：情報密度を落として呼吸を作る。
6. **ブランド部品を追加**：Thank You スクリプト・クーポンチケット形状・メール/電話アイコン・numbered step・スマホモックアップ。

### コンテンツ整合
7. **コピー／IA を人力版に合わせる**：Hero コピー、実クーポンコード、B 裏の構成（購入フロー＋栄養サポート）を確定。

## 🔁 Flywheel への学び（最重要・④）

**figma-bridge による AI 構造組成は「7割」ではなく「ワイヤーフレーム（3〜4割）」だった。** デザインの craft（写真主導構図・ジャンプ率・色ゾーニング・ブランドアクセント）は丸ごと人間側に残る。

→ Flywheel の役割分担を再定義：

| 案 | AI の役割 | 人間の役割 |
|---|---|---|
| **現状（figma-bridge 直組み）** | ワイヤー（構造・コピー・色トークン配置）= 3〜4割 | デザイン craft 全部 = 6〜7割 |
| **改善案A（spec を厚く）** | 写真配置・カラム・ジャンプ率・色ゾーニングまで**指示書**で指定（v1 を拡張） | Figma で craft を実行（指示が明確なら速い） |
| **改善案B（参照デザイン先行）** | 人力サンプルを「型」として読み込み、新規案件はその型に流し込む | 写真選定・微調整のみ |

**推奨**：改善案B。**今回の人力4枚を「FAMBOX チラシ・テンプレート v1」として型化**し、次案件（次シーズン／別チラシ）はその型へコピー差し替えで回す。これが「誰でも7割を早く」に最短。
→ 関連学び：[[feedback_visual_design_video_first]]（視覚は実物先行）と同じ構造。**チラシも実サンプル先行が正解**。
