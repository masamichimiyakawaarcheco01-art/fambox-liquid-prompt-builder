## 🎯 全体方針

### 既存 FAMBOX MENU CATALOG（B 向け 11ページ）を踏襲

ユーザー添付の MENU CATALOG（カタログ）から以下を継承：
- **Drive Orange #FB4C15** の塊（badge / hero band / bottom CTA）
- **白背景 + ink#1B1D1A 文字**
- **三角コーナーアクセント**（オレンジ）
- **「+」プラスマーク**装飾
- **英語セクションラベル**（OUR STORY / SOLUTION 等）
- **ページ番号オレンジ rectangle**（右下）
- **大前 + 和田 ペアショット**（信頼の核）

### C 向け / B 向けの差分戦略

| 観点 | C 向け（個人アスリート）| B 向け（実業団・チーム）|
|---|---|---|
| 受け取り場所 | 自宅冷凍庫 | チーム寮・合宿先 |
| 心理状態 | 「冷凍庫保管 → トレ後・夜食」 | 「導入効果あるかな」 |
| Hero 訴求 | 「アスリート飯を、自宅の食卓に」 | 「強いチーム作りの土台に」 |
| 3 ポイント | 体感・継続・手軽さ | 専門性・負担軽減・費用対効果 |
| CTA | 定期購入 LP + Instagram | 法人窓口フォーム + 無料トライアル |
| クーポン | 個人定期 OFF | 法人プラン or 資料請求特典 |

### 共通要素（両方に入る）

- FAMBOX とは（説明）

#### 2. ISSUES — こんな課題ありませんか？

```
① 日常の食事がコンビニ・外食になりがち
   フィジカル強化を図りたいが、選手の自炊や外食に頼っている。

② 寮・食堂で食事が出ない時がある
   寮や食堂がお休みの土日祝日や、1 日のうち不足する分の食事
   までサポートしきれていない。

③ 遠征・合宿時の食事の不安
   遠征先や合宿所の食事環境では、コンディション維持や
   大事な試合でのパフォーマンス発揮に不安がある。

④ 環境改善の予算と時間不足
   食事の環境を良くしたいが、専属の栄養士を雇ったり、
   専用の食堂を作る「予算」と「時間」がない。
```

#### 3. SOLUTION — FAMBOX なら解決できます

```
いつでも、どこでもアスリート食を、FAMBOX なら解決できます。

① トップアスリート現場の食事
   プロ野球や日本代表を支えたスポーツ栄養の専門家が
   メニューを設計。

② 選手の自炊負担を大幅軽減
   冷凍宅配だから、自宅・遠征先・合宿所を問わず導入可能。

③ 優れた費用対効果
   栄養士の雇用や食堂の設置に比べて、大幅にコストを抑えて
   導入・運用が可能。
```
