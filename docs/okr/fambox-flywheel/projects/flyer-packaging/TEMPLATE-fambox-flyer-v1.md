## スタイル宣言（Marc式・スコープ付き）

> 曖昧な「Editorial × Lab」を正規化。Lab感は別スタイルでなく Editorial の「精度（情報設計）」に内包。secondary 3つ以上は決定回避＝禁止。

```yaml
primary: editorial-premium        # 余白・グリッド・タイポ階層・写真主導を全体支配
```

## タイポグラフィ規律（Marc式・数値）

- **トラッキング**：Display40+ `-4%` / 28-39 `-3%` / 20-27 `-2%` / 16-19 `-1%` / 本文13-15 `0` / 小12以下 `+1%`
- **行間**：Display 1.05-1.10 / 見出し 1.15-1.25 / 本文 1.50-1.60 / キャプション 1.30-1.40
- **見出しに Bold700 禁止**（Semibold600 まで）
- **本文幅は利用可能幅の 70-80% のみ**（混雑＝アンチパターン、余白＝エディトリアル）。1行 60-75文字（JA は 20-32字）

## 間(ma)スケール（指数・等差禁止）

`4 / 8 / 16 / 24 / 48 / 80 / 120 / 200`（section内=48-80 / major=120 / chapter=200）。
**12 / 20 / 32 / 40 は文書化された正当化なしに使わない**。y座標を等差でなく指数リズムで配置。

## アンチパターン ❌（配置前チェック）

- サンセリフのみ（Editorial はセリフ/特徴書体を含む）
- ストック写真の安易な使用（焦点で切る・コミッション推奨）
- 彩度の高い全幅ベタを2面隣接（白で分離）
- 全幅サンドイッチ（上下ベタ＋中白）
- アイコンの塗り/線の混在（Lucide 2px に一本化）
- 本文幅 80% 超
- **押し売り・空語**：「今だけ」「今すぐ」「お見逃しなく」「最高の」「プレミアム」「revolutionary」「業界No.1」→ Words-first 監査（「74歳のご近所さんが言うか」テスト）を**配置前**に

## 5. この型の使い方（次案件フロー）

1. **複製**：人力4枚を複製 → 新フレーム名にリネーム
2. **差し替え**：M-XX モジュール単位で、写真・見出し・本文・クーポン値を新案件用に置換
3. **固定で触らない**：グリッド・フォント体系・色ゾーニング・M-10〜M-13（裏面下半分共通）はそのまま
4. **AI の関与点**：コピー生成（v1 spec 方式）＋差し替えデータ表（§4 形式）の作成＋校正。**レイアウト craft は型が担保**するので、AI は「中身」、型は「器」。

→ これにより figma-bridge でゼロから組む（3〜4割・ワイヤー）より、**型流用（7割スタート）**が速く確実。

### 指示テンプレート（冒頭に固定・Marc式 Source宣言＋構造化spec）

```
# Source declarations（着手前に audit-first）
- 型(spec): TEMPLATE-fambox-flyer-v1.md
- 参照画像: reference/human-{C,B}-{front,back}.png ← 「この画像に合わせ差分を自己批評して直せ」
- Asset manifest: /Users/archecoinc./Desktop/Claude_1/Asset/（写真）
- tokens/brand: fambox-design 01-tokens / Brand DNA / bugs.md DOCTRINE-006/007
- 差し替えデータ表: §4（TBDゼロ・実値）

# 構造化spec で明示する5フィールド（手動パースで漏れる）
- fills[i].opacity（色とopacityは別。rgba()に焼かない）
- hierarchy: フラット配列＋depth整数（ネスト木で渡さない）
- effects[i].blendMode（multiply/screen は平色再現不可）
- variableBindings（tokenバインドかリテラルか）
- layout.primaryAxisSizing（FILL/HUG/FIXED）

# 写真指示語彙
- scaleMode: CROP/FILL ＋ focal point（焦点）／「フルブリード or 厳密整列」の二択
```

### モジュール改変規律（各 M-XX に付与）
- **触OK**：写真・見出し・本文・差し替え値
- **触禁止（Forbidden modifications）**：パディング・色・配置・装飾の追加
