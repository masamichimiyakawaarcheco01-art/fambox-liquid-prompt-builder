```
🎯 *第一弾プロジェクト：FAMBOX 梱包用チラシ作成の自動化*

Flywheel Step 1 として、最初の実案件は
*FAMBOX 梱包に同梱するチラシ作成の自動化* に着手します。

【何を作るか】
A4 比率のチラシを *2 タイプ*（Figma で制作）：
• *C 向け* — 個人顧客に届く（商品体験・栄養・調理など）
• *B 向け* — 法人顧客に届く（健康経営・組織パフォーマンスなど)

【なぜこれを第一弾に】
• *顧客に物理的に届く* アウトプット → フィードバックが取りやすい
• AI 自動化の効果が直接見える（速度・品質の両方）
• *紙媒体 AI フローの試金石*
  → 後続のパンフ・印刷物・他フォーマットへの応用基礎に

【進め方】
4 ステップループを愚直に回します：

```
① インプット   依頼内容・素材・要件をテンプレ化
       ↓
② 生成        AI でドラフト(Figma + AI 連携)
       ↓
③ レビュー修正 「FAMBOX らしさ」を調整、繰り返し
       ↓
④ 学び        失敗・改善を bugs.md とフローに反映
       ↓
   次のチラシ案件へ(蓄積されて速くなる)
```

最終目標：*7 割品質を 1〜2 時間で出せる* 状態。
Web/Liquid に続いて、紙媒体でも 7 割品質を AI で量産可能に。

【協力歓迎】
• C 向け / B 向けで *「こんな内容を載せたい」あれば* 気軽に Slack
• 過去の良かった事例・参考にしたいデザイン共有歓迎
• 試作完成したら *フィードバック* もらえると嬉しいです
  特に「FAMBOX らしさ」観点

進捗は毎週月曜の Weekly 宣言で報告します。
今週から着手します 🙏

#FAMBOXFlywheel #第一弾チラシ自動化
```

## 🎯 このプロジェクトを「第一弾」に選んだ理由

### 3 つの戦略的妥当性

| 観点 | 理由 |
|---|---|
| **フィードバック獲得** | 顧客の手元に物理的に届く = 反応が直接見える |
| **領域拡大** | Web/Liquid は既に7割出る → **紙媒体は未開拓フロンティア**（D-028 整合）|
| **応用可能性** | A4 チラシで型ができれば、パンフ・はがき・印刷物全般に波及 |

### Flywheel 設計上の意義

- Step 1 の **「個人インフラが10倍速」** を実証する最初の事例
- ④学び → bugs.md 拡張 = Marc 評価「the real Learn loop」を回す
- C/B 2 タイプ = **依頼者ペルソナの違い** を最初から織り込み（Step 2 への布石）
