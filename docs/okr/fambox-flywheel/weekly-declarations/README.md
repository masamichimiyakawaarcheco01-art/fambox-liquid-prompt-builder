# Weekly Declarations — 宣言駆動 Weekly Cycle

> **目的**：宮川さんの「迷いやすい」「アクション落とし込みが苦手」特性を克服するための仕組み。
> 公共宣言の緊張感を使って Flywheel 構築を加速させる。
> 須藤さん助言（[2026-05-28 会話](../sessions/2026-05-28-sudo-career-conversation.md)）が起点。

最終更新：2026-05-28（運用開始：Week 2 = 2026-06-02 から）

---

## 🎯 このシステムが解く問題

| 問題 | 解決策 |
|---|---|
| 計画を立てると「やってる気」になり、実は倒れているだけ | **公共宣言で逃げ場を断つ** |
| 1週間の計画が壁で頓挫しても、ずれが整ってしまう | **毎週月曜にリセット + 新宣言** |
| 深く考えすぎて行動が遅れる | **「スピード 10 / 品質 7」**、完璧禁止 |
| 1人で進めると孤独で停滞しがち | **Marc・須藤・チームが見ている状態** = 援護射撃 |

---

## 🔁 サイクル（毎週）

```
月曜（朝）  #int-general に投稿
            ↓ 宣言 + 先週のアウトプット
            ↓
火〜木    実行（緊張感を持って）
            ↓
金曜      事業開発で進捗発表（既存運用）
            ↓
週末      retro（reflect）
            ↓
月曜（朝）  次週の宣言投稿
```

---

## 📝 月曜投稿の中身（テンプレ：`template.md` 参照）

各週の投稿は以下3パートで構成：

1. **✅ 先週のアウトプット**（成果物 + 学び）
2. **🎯 今週の宣言**（具体的アクション、最大3つ）
3. **📈 Flywheel 進捗**（現在位置 + 次マイルストーン）

---

## 🚫 やってはいけないこと

| NG | なぜ |
|---|---|
| 完璧を求める | 品質 7 で OK。10 目指すと止まる |
| 5つ以上の宣言を並べる | 1週間で 3つ以上はパンクする |
| 抽象的な宣言（「頑張る」「進める」）| アクションが明確じゃないと逃げ場ができる |
| 月曜にずらす（火曜投稿）| 緊張感が消える |
| 先週倒れた項目を「来週やります」だけで済ます | 倒れた理由 + 対策を明示 |

---

## 🎮 ゲーミフィケーション要素

- **連続投稿週**：何週連続で月曜投稿したか
- **宣言達成率**：先週宣言した 3項目のうち何個達成したか
- **援護射撃ログ**：Marc / 須藤 / 他からのリアクション

これは **「YouTuber 宮川流ノリ」**（須藤さん発言）で気軽に。深刻に取りすぎない。

---

## 💬 投稿のトーン

- **カジュアル + 真剣**（マニフェストではない）
- 絵文字 OK、自分の言葉で
- 失敗・倒れも正直に書く（むしろ書く）
- 「みんなに見られてる」を意識した自分への締め付け

---

## 📊 月次レビュー（毎月最終週の月曜投稿で兼ねる）

その週の宣言に加えて、月次サマリを含める：

- その月の宣言達成率
- 最も価値を生んだアクション
- Flywheel Step 進捗 vs マイルストーン
- 次月のテーマ

---

## ⚠️ 緊急ルール：「3週連続で宣言の半分以上が倒れたら、計画を疑う」

宣言サイクル自体は強力だが、構造的に無理がある場合は計画を見直す：

- Step 1 のスコープが大きすぎる
- 別優先業務が侵食している
- 個人モチベーションが下がっている

3週連続で半分以上倒れた場合、**須藤さん or Marc と 1on1** で立て直す。
