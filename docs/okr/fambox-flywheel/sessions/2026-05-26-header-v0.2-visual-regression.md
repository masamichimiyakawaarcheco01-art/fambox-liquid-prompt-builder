## 4. コンテンツ差分（Theme Customizer で吸収）

本番反映 GO 後、Shopify 管理画面の Theme Customizer / メインメニューで以下を切替えます。**コード変更は不要**。

| 項目 | Figma カンプ（B2B 寄せ） | 実装プレビュー（B2C 寄せ） | 切替方法 |
|---|---|---|---|
| CTA ラベル | 「話を聞いてみる」 | 「法人・プロ」 | Theme Customizer → Header section → `corp-btn text` |
| Nav 項目 | 4 件（商品 / 事例 / ブログ / ご相談） | 6 件（ホーム / 食事診断 / プラン / 事例 / ブログ / お問い合わせ） | Shopify 管理画面 → メニュー → メインメニュー差し替え |
| Icon 数 | 2 個（Account / Cart） | 3 個（検索 + Account + Cart） | section setting で検索 icon 表示/非表示切替 |

> **判断ポイント**：B2B 専用ページ（`/pages/tokusetsu-jisseki` 等）では「商品 / 事例 / ブログ / ご相談」+「話を聞いてみる」表示、B2C 通常ページでは現状維持、の **2 セット運用** を提案します。
