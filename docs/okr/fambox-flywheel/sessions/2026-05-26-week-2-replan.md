→ Claude のリフレーミング：
- マーク領域（右側）と宮川領域（左側）は **ドメインが違うだけ**。優劣ではない
- 英語の壁は Claude 翻訳で克服可能
- ウォーターフォール懸念は **週次マイクロデリバラブル** に切り替えれば解消

## 8. Purpose と Goal Image の言語化

> 宮川さん：「まずはこの構想の目的と何をやろうとしているのかのゴールイメージ、その上での手段の話だと思います」

これを受けて Claude が Purpose / Goal Image / Positioning を提案：

### Purpose（D-015 確定）

> **「誰でも 7割の質のアウトプットを早く出せる、AI と Design の仕組み（インフラ）を作る」**

→ 宮川さん「FAM の中で深掘り続けたいわけではない。Marc のように 7割の質を誰でも早く出せる AI と Design の仕組み（インフラ）を構築したい」

### Goal Image（D-016 確定）

3段階で MVP に到達：
- Step 1：宮川さん個人インフラ完成（10倍速）
- Step 2：須藤・松浦・三宅・マレル・安原等が指示書ドライブ
- Step 3：誰でも使える = Flywheel MVP 完成

→ Step 3 の先（新領域開拓・マルチブランド）は **MVP の外側** に意図的に置く

## 9. 「左 vs 右」の認識訂正（重要）

Claude の当初理解は誤り。宮川さんからの訂正：

| 旧理解（誤）| 新理解（正）|
|---|---|
| 右側 = リソース豊富 / 左側 = 孤独 | 右側 = Wide & Shallow（多サービスに浅く広く） / 左側 = Deep & Narrow（1事業に狭く深く） |
| 優劣がある | 得意不得意が違うだけ、両方 valid |

これは設計全体に影響する訂正。

## 10. ポジショニング：Middle & Fast（D-017）

Claude 提案：「Deep & Fast」 → 宮川さん訂正：「**Middle & Fast** のほうがしっくり来る」

Middle の意味：
- 1事業（FAM BOX）固定ではなく、関連ブランド群（FAM / Lemon / 将来）に展開可能
- でも Marc のような「多数の無関係なサービス」までは広げない
- マルチブランド対応の **基盤** になる中間ポジション（D-008 と整合）

```
              狭　　　　　　　　　　　　　広
          ┌─────────────────────────────────┐
   速 ↑   │ Deep & Fast │★Middle & Fast│ Wide & Fast │
        │             │  (宮川さん)  │  (Marc)     │
        ├─────────────────────────────────┤
        │ Deep & Slow │ Middle&Slow │ Wide & Slow │
   遅 ↓   │ (従来)       │              │             │
          └─────────────────────────────────┘
```

## 11. Step 2 インプット設計（D-018）

| 項目 | 値 |
|---|---|
| 形式 | **Standard**（30分で書ける B レベル） |
| 依頼者 | 須藤・松浦・三宅・マレルチーム・安原さん 他 |
| 頻度 | 週5件（チーム全体合計） |
| 媒体 | Slack |

重要原則：
- 背景情報（FAM Brand DNA / DS / 過去資産）はインフラが自動付与
- 依頼者は「今回固有の情報」のみ書く
- Slack ワークフロー / フォーム化を検討

## 12. Marc 連携運用（D-019）

> 宮川さん：「Marc さんへの質問は必要になったときに質問したい」

→ 採用された方針：
- 概要だけ最初に共有（Purpose / Goal / Positioning + 既存資産）
- 詳細質問は手を動かす過程で出てきた時に都度
- イテレーティブな peer 関係（front-load しない）

## 13. 「7割 / 3割」の境界（D-020）

明文化：
- **AI が担う 7割**：構造 / ブランド準拠 / 初稿コンテンツ / アセット配置 / コード
- **人間が詰める 3割**：コピーの魂 / 画像最終選定 / 案件固有事情 / 最終品質チェック
