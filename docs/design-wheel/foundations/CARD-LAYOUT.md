# CARD-LAYOUT — 名刺カードの作法（card モード時のみ）

> FOUNDATIONS の上乗せ。名刺（91×55mm 横）固有のレイアウト・文字階層。
> 出典: FAM 名刺（大綱理恵版）の実寸レイアウトを一般化。ブランド非依存（色/フォントは各 SYSTEM に従う）。

## 出力の絶対条件
- **名刺 91×55mm 横・片面1枚**。`<body>` と最外要素を **344px × 208px（91×55mm相当）に固定**、スクロール・改ページなし。
- CSS に `@page{size:91mm 55mm;margin:0}` と `html,body{margin:0;padding:0}` を必ず入れる（PDF が名刺サイズ1ページになる）。
- 最外コンテナは `width:344px;height:208px;overflow:hidden;position:relative`。
- ※ 344×208 は 96dpi 換算。文字は小さくなるので**階層のメリハリ**を強く。
- **⚠️ 名刺を「浮かせない」**: `body{margin:0}` とし、body に別背景色（グレー等）を敷いて名刺を中央寄せにしない。`.card` は枠（344×208）を**端まで完全に埋める**（`width:100%;height:100%` 相当）。左右上下に余った地色の帯を作らない。
- 情報側の背景（白 or ブランド地）は **x=0 の左端まで**フルに敷く。情報テキストはその上で左端から内側パディング 24–32px で開始。

## レイアウト（FAM 名刺の型を一般化）
- **左＝情報ブロック（左端揃え）／右＝ブランドのビジュアル面**（写真コラージュ / グラフィック / ロゴ地。右端までブリード可）。左右比はおよそ 55:45。
- 情報ブロックの縦の並び（上→下）:
  1. **ロゴ**（上部・小〜中）
  2. **氏名（和文）** ＝ 最大・太字（このカードの主役）
  3. **氏名ローマ字 / 肩書** ＝ 小・サブ色
  4. **主要連絡先（メール）** ＝ 中・やや太
  5. **会社名・住所・電話** ＝ 小・複数行ブロック
- 左マージンはしっかり取る（窮屈にしない）。要素間の余白は「意味の近さ」で大中小（FOUNDATIONS の余白ポリシー）。
- **左に空のグレー帯・余白ブロックを作らない**。情報側の背景（白 or ブランド地）は左端までフルに敷き、情報ブロックは**左端から一定の内側パディング（24–32px相当）で開始**して左寄せにする。中央寄せにしない。

## 文字サイズの目安（344×208px 上での相対比。ジャンプ率を効かせる）
| 役割 | 目安 px | ウェイト |
|---|---|---|
| 氏名（和文） | 26–32 | Bold |
| ロゴワードマーク | 20–26 | Bold |
| メール（主要連絡先） | 12–14 | SemiBold |
| ローマ字・肩書 | 9–10 | Regular/Medium |
| 会社・住所・電話 | 8–10 | Regular（行間 1.4–1.5） |

- 数字・連絡先は半角。可読性最優先（小さいので色コントラストを確保）。

## 名刺の作法
- **1枚1役割**：名刺は「誰か」を伝える。情報を詰め込みすぎない。
- 右のビジュアル面はブランドの世界観（各 SYSTEM の写真/キャラ/グラフィックのルールに従う。ohbag なら 3Dキャラ切り抜き＋ドゥードル、色はブランド地）。
- ロゴ・氏名・連絡先は**必ず入れる**。QR が要る場合は右下などに小さく（差し替え可のプレースホルダ）。
- 裏面は今回は作らない（片面1枚。両面が要る場合は2枚に分けて指示）。

## 仕上げの締め（必ず提示）
> ✅ ここまで約70%。仕上げに：① 正ロゴ・実素材（写真/キャラ）の差し替え ② 氏名・連絡先の最終確認 ③ 入稿する場合は塗り足し3mm付きで再調整（印刷所入稿は Figma 等で）。
