## 1. Identity
- **パターン名**: digital
- **一言定義**: 「計測・規格・精密」を感じさせる語彙（計測線・モノスペース・bento グリッド・数字の主役化）で先端感を作る様式。彩度は図形・被写体に限定し、UI シェルはグレー＋黒に徹する。corporate が「余白の信頼」、sporty が「運動量の説得」なら、digital は**「精度の説得」**。

## 2. Color
| 役割 | 値 | 用途 |
|---|---|---|
| bg | #9FA0A3 | 画面背景（**中明度グレー** — Reown 型。白でも可だがグレーが識別子） |
| surface | #F2F2F0 | カード/面（オフホワイト） |
| surface-dark | #161618 | 黒カード（bento に混ぜる） |
| ink | #111114 | 主テキスト |
| ink-muted | #77777E | 副テキスト・計測ラベル |
| accent-r / accent-y / accent-b | #F04E23 / #F5B800 / #2D6BFF | **原色は複数可。ただし幾何図形・カード面に限定**（テキスト/罫線には使わない） |
| line | #D9D9DB | 計測線・hairline |

**ゾーニング規則**: bento タイル＝surface と surface-dark の混成リズム。原色は「タイル1〜3枚」「幾何アイコン」「抽象UIモック」にだけ。写真より**3Dレンダー/抽象図形**を優先し、彩度を被写体に集中（Andy Lin 原理）。

## 3. Type
- **書体方針**: 本文・ラベルに**モノスペース**（JetBrains Mono / Space Mono 系）を積極使用。見出しはグロテスク sans または細身ワイド。数字・データは最大級に主役化してよい（虎ノ門型）。
- **6段スケール（PC）**: 飾り/数字 96px(w300〜500・トラッキング広) / 大H1 40px(w600) / H2 24px(w600) / H3 16px(w600・mono) / Body 13px(w400・mono) / Small 10px(w500・mono・uppercase)
- **ジャンプ率**: **二極**（特大数字/飾り vs 小さい mono 本文。中間を置かない）
- **行間**: 見出し 1.1 ／ 本文 1.65

## 4. Layout
- **グリッド**: **bento**（不均等だが規格化されたタイル）。基準 12カラム / ガター 16px（タイトに）。
- **整数比**: タイルは 1:1 / 2:1 / 3:1 の整数比のみ。
- **余白 S/M/L（等比 2x）**: S 12px / M 24px / L 48px（corporate より一段詰める＝密度が精密感を作る）。

## 5. Components
| 要素 | 角丸 | 影 | 状態 |
|---|---|---|---|
| カプセルブロック | 高さの50%（999px） | なし | hero/フッタ CTA の主役形状 |
| bento タイル | 20px | なし | hover で僅かに明度変化 |
| ピルボタン | 999px | なし | 塗り=ink または accent |
| 計測線・ラベル | — | — | line色 1px ＋ mono 極小キャプション |
| 番号カード | 16px | なし | 01-04 mono 番号（corporate と共通語彙） |
| 抽象UIモック | 24px | なし | 実画面でなく図形化したデバイス/画面 |

## 6. Motion
- **速度**: 0.25s ／ 数字・データ系はカウントアップ/フリップ演出可
- **イージング**: linear 寄り（機械的）または steps()（フリップ） — ease-out の「人間味」をあえて避ける

## 7. DO / DON'T
- ✅ DO: bento の規格タイル／モノスペースのラベル・本文／数字・データの主役化／計測線・極小キャプション／彩度は図形と3Dレンダーに集中／黒タイルの混成／カプセル形状／ブラー=時間・動きのメタファー（装飾でなく意味で使う）。
- ❌ DON'T: 有機的な曲線・手書き要素（gradient/playful の領分）／テキストへの原色使用／写真の多用（彩度が散る）／余白を広げすぎて corporate 化する／装飾シャドウ・グロー多用。
