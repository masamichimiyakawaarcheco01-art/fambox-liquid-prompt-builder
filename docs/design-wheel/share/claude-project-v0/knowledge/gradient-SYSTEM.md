## 1. Identity
- **パターン名**: gradient
- **一言定義**: 粒子（grain）質感のソフトなグラデーションを「器」に閉じ込め、白いシェルに浮かべる様式。要素最小主義で、柔らかさ・クリエイティブ・軽やかさを作る。**「感性の説得」** — corporate（余白の信頼）/ sporty（運動量）/ digital（精度）と並ぶ第4の説得軸。

## 2. Color
**シェル（UI）とグラデ（彩色）を完全分離**するのが鉄則。

| 役割 | 値 | 用途 |
|---|---|---|
| bg | #FAFAF7 | 画面背景（白〜アイボリー） |
| surface | #FFFFFF | カード/紙面 |
| ink | #141416 | テキスト（黒のみ。彩色テキスト禁止） |
| ink-muted | #8C8C90 | 副テキスト |
| line | #E8E8E4 | 細枠ボタン・hairline |
| **grad-warm** | #FF8A3D → #FF4FA0 | グラデ素材A（暖色系） |
| **grad-cool** | #5AC8FF → #7B5BFF | グラデ素材B（寒色系） |
| **grad-fresh** | #9BE15D → #00E3AE | グラデ素材C（フレッシュ系） |

**ゾーニング規則**: グラデは必ず**器に閉じ込める**（直接背景に塗らない）。器は3型 — ①規格形状（円/半円/カード） ②有機ブロブ ③文字クリッピング。**grain（粒子）質感を必ず併用**（ベタCSSグラデは安っぽくなり禁止）。

## 3. Type
- **書体方針**: 太ゴシック（塗り）と**アウトライン（縁線のみ）**の2モード。アウトライン文字は「奥の層」として使う。日本語は太ゴシック。
- **6段スケール（PC）**: 飾り/Display 120px(アウトライン可・w700) / 大H1 48px(w700) / H2 28px(w600) / H3 18px(w600) / Body 14px(w400) / Small 11px(w500)
- **ジャンプ率**: 高（ただし sporty のような uppercase 圧はかけない。小文字混じりで柔らかく）
- **行間**: 見出し 1.05 ／ 本文 1.7

## 4. Layout
- **グリッド**: 中央寄せ・対称基調（corporate/digital の左寄せグリッドと差別化）。12カラム / ガター 24px。
- **整数比**: ブロブ・器は画面の 1/2〜2/3 を占有してよい（主役）。
- **余白 S/M/L（等比 2x）**: S 16px / M 32px / L 64px。**要素数は最小に**（テキストロック2〜3個まで／HELMO 原理）。

## 5. Components
| 要素 | 角丸 | 影 | 状態 |
|---|---|---|---|
| グラデカード（器①） | 12px | **ソフトシャドウ**(0 24px 48px rgba(0,0,0,.08)) | ±2〜6° 回転散布可 |
| ブロブ（器②） | 有機形状 | ソフトシャドウ | 浮遊感（ゆっくり上下アニメ可） |
| 文字クリップ（器③） | — | なし | グラデを文字で切り抜く |
| ボタン | 4〜8px | なし | **細枠線**（塗りボタンは使わない） |
| 手書き注釈 | — | — | 矢印＋小さな手書き風キャプション（人の手の気配） |

## 6. Motion
- **速度**: 0.6s〜（**ゆっくり** — 速い動きは柔らかさを壊す）
- **イージング**: ease-in-out。ブロブの浮遊・グラデの緩やかな変化

## 7. DO / DON'T
- ✅ DO: grain 質感の必須併用／グラデを器に閉じ込める／白シェル＋黒テキスト厳守／要素最小主義／アウトライン文字=奥・溶け込み=境界の深度2型／ソフトシャドウの浮遊感／手書き注釈／同一形状×グラデ差替のバリエーション展開。
- ❌ DON'T: ベタCSSグラデ（grainなし）／背景全面へのグラデ直塗り／彩色テキスト／要素過密（4ロック以上のテキスト）／硬いシャドウ・枠線／高速アニメ／uppercase の圧。
