# BRIEF — 条件の翻訳（Layer ③）

> Layer ①（FOUNDATIONS＝普遍の骨格）と Layer ②（各 SYSTEM＝ブランドの意思）の上に乗る、**「この1回をどう作るか」を決める条件レイヤー**。
> 非デザイナーは条件を断片でしか言わない。**この型で最低限を埋め、優先順位 → パラメータに翻訳**してから作る。聞きすぎない（最初の1往復で足りない所だけ）。

---

## A. 最低限ヒアリング（無ければ1度だけ聞く）

| # | 問い | 何に効くか |
|---|---|---|
| 1 | **何を・誰向けに**作る？ | パターン選択・トーン |
| 2 | **媒体とサイズ**（Webページ / バナー / 表紙、比率） | 構図・固定サイズ可否 |
| 3 | **一番伝えたい1メッセージ**は？ | 最大ジャンプ率を当てる主役 |

これ以上は聞かず、下の6因子は**言われた範囲で埋め、空欄はパターンのデフォルトで補completion**する。

---

## B. 6因子（条件の分解 — 言語化の引き出し）

非デザイナーの「なんかいい感じ」を、この6軸で具体化する。全部埋める必要はない。

1. **USER（誰が見る）**: 年齢層・リテラシー・閲覧文脈（移動中スマホ / 業務PC など）
2. **BRAND（らしさ）**: 既存トーン・NG表現・ロゴ/指定色の有無
3. **SENSE（出したい雰囲気）**: 信頼/先端/温かみ/熱量… → これが**パターン選択**に直結
4. **PROJECT（用途と目的）**: 告知 / 集客LP / 採用 / 商品紹介 / 資料 …＋達成したい行動（CTA）
5. **SOCIETY（いまの空気・流行）**: 季節・トレンド・時事（※流行は装飾に留め、骨格は崩さない）
6. **COMPETITOR（差別化）**: 似せたい/避けたい参照。**色・フォントは引用せず、構図/モーション/レイアウトのみ参考**にする

---

## C. 条件 → パラメータ翻訳表

集めた条件を、FOUNDATIONS の操作レバーに変換する：

| 条件 | 動かすレバー |
|---|---|
| 高級・信頼・きちんと | ジャンプ率**低** / 余白**大** / 装飾控えめ → 多くは **corporate** |
| 先端・精密・データ | 密度高 / データ可視化部品 / 暗色 → **digital** または **sporty(product-UI)** |
| 熱量・運動・躍動 | ジャンプ率**高** / 強いキャラクターライン → **sporty** |
| 温かみ・感性・余韻 | グラデ/階調 / やわらかい余白 → **gradient** |
| スマホ・移動中閲覧 | 主役を1つに / タップ領域大 / 縦構図 |
| 情報量が多い | カード/リストで分節 / 余白ポリシー厳守 / 同じ意味=同じ寸法 |
| CTAで行動させたい | CTA を最大コントラスト・Primary・1画面1主役 |

---

## D. 媒体・サイズ → 構図

| 媒体 | 構図の原則 |
|---|---|
| Webページ（LP等） | レスポンシブ・縦長可。ファーストビューに主役1つ＋CTA |
| バナー1枚 | 指定比率に**固定**・はみ出しなし・単一構図。文字は最小限・ジャンプ率高めで視認性 |
| Instagram | 1:1(1080²) / 4:5(1080×1350) |
| TikTok / Stories | 9:16(1080×1920) |
| YouTube サムネ | 16:9(1280×720) |
| ブログ OGP | 1.91:1(1200×630) |

---

## E. 矛盾したら「分割」する

条件が衝突したとき（例: 「高級感も欲しいし躍動感も欲しい」）は混ぜて中途半端にしない：

- **主役の条件を1つに決める**（最大ジャンプ率・最大面積を割り当てる軸）。
- 副次条件は**別ゾーン or 別バリエーション**に逃がす（例: メインは静かに、CTA周りだけ熱量）。
- どうしても二者択一なら「**どちらを優先しますか？**」と最大3択で1度だけ聞く。

---

## 使い方（運用）
1. 依頼を受けたら A を確認（足りない所だけ1往復）。
2. B で言語化、C でパラメータに翻訳、D で構図を確定。
3. パターン（Layer ②）を1つ推薦 → FOUNDATIONS（Layer ①）の作法で生成。
4. 締めに「ここまで約70%。仕上げ3チェック（ロゴ/実写真・文言・ブランド固有要素）」を提示し、FB を促す。
