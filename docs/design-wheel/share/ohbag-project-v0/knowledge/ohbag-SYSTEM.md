## ブランド核（decode）
- 正体: **AI travel concierge**（旅の全部を1つのチャットで）。タグライン **"Your whole trip, in one chat."** / **"Your AI travel concierge"**。

- 声のトーン: 会話的・簡単さ訴求。キーフレーズ: "Just ask ohbag" / "Just message ohbag — it handles the rest" / "No app-juggling, no phone calls, no paperwork" / "Travel lighter, plan smarter"。命令形でなく誘い。

## ohbag 絶対ルール（世界観ガイド。これを外すと ohbag でなくなる）
- **ライムグリーンが主役**。明るいシャルトリューズ green を背景パネルに大胆に使う。くすませない・暗くしない。
- **すべて角丸**（大きめ radius）。フォントも丸みのある geometric sans。硬い・角ばった表現を避ける。
- **人物は 3D キャラ**（クレイ/Memoji 調の多様な旅行者）。**実写ストック写真やフラットなクリップアートで代用しない**。素材が無ければグレーボックス＋「3Dキャラ差し替え」で置く。
- **見出しはインディゴ、本文はネイビー、面は白＋ライム＋ラベンダー**。彩度の高い面を濁らせず、余白で軽やかに。
- コピーは**短く・会話的**（"Just ask" 調）。専門用語で固くしない。
- 多言語前提（英語主＋日本語、欧米ゲスト向け）。見出し英語＋日本語サポートで併記可。

## タイポグラフィ（Google Fonts で実レンダリング。★実サイト CSS で確定済 2026-07-03）
- **見出し（Display）= Poppins**（wght 500/600/700/800）。CSS 変数 `--display:'Poppins'`。
- **本文（Body）= Manrope**（wght 400/500/600/700）。CSS 変数 `--body:'Manrope'`。
- 日本語 = **Noto Sans JP**（`'Noto Sans JP', sans-serif`）。
- 読み込み: `https://fonts.googleapis.com/css2?family=Poppins:wght@500;600;700;800&family=Manrope:wght@400;500;600;700&display=swap`
- 見出し: **インディゴ `#3D39D6`・Poppins 700/800・2行**（例: "Your whole trip, / in one chat"）。字間わずかにタイト。
- 本文: ネイビー・Manrope 400/500、短く。行間 1.6〜1.75。
- ALL CAPS は**字間広めのラベル**（ナビ/フッター）に限定使用（ref の "TU SONRISA EN MOVIMIENTO" 調）。

## テイスト・モード（既定 = B Energetic。SNS/現地チラシは B、公式・アプリ紹介は A）
### A. Clean（アプリ紹介・公式）
- 現行 App Store 調。白基調＋ライム/ラベンダーの大角丸パネル、iPhoneモックアップ＋3Dキャラ、余白ゆったり・整然。信頼・説明向け。

### B. Energetic Cutout-Doodle（既定・SNS/現地映え。ref: SMOOV/Evelyn/letboss から decode）
- **ベタ塗りの大角丸パネル**（ラベンダー/インディゴ面）を主面にし、**3Dキャラを切り抜いてパネルからはみ出させる**（境界ブリッジ）。
- **ライムグリーンを"効かせ役"に**：太いループ状の手描き線・手描き文字（"hello!" "こんにちは" 調）・ロゴチップ。1画面に1〜2箇所だけ大胆に。
- **手描きドゥードル**：うねる線・スクリブル・**✦スパークル**・黒の走り書きストローク。overlay で人物の前後に重ねる。
- **吹き出し**で短い挨拶/ひとこと（"hello ooo!" のノリ、ohbag は "Just ask ✦"）。
- **丸いピルボタン/タグ**（NUEVA/SONRISA 調）。上下に**字間広めの大文字ラベル**（ナビ/フッター）。
- 躍動感・若々しさ・高コントラスト。ohbag 配色は不変（ライム/ラベンダー/インディゴ/ネイビー/白）。
- **注意**: 実写ストック写真は使わない（人物は 3Dキャラ切り抜き）。ドゥードルは手描き風 SVG/太ストロークで、雑にしすぎない。
