# 現地シナリオ入力テンプレ（現場でコピペして Project に貼るだけ）

> 前日の気づき → 翌日のツール、を最速で回すための入力型。埋めて Project に送れば叩き台が出ます。

```
【誰に】            （例: チェックイン直後の欧米ゲスト / 家族連れ / 連泊のビジネス客）
【シナリオ・一番の訴求】（例: 東京→京都へ荷物を送りたい → ヤマト手配機能）
【媒体】            A4チラシ / 名刺カード / SNS投稿（4:5）
【テイスト】        B Energetic（既定・掴み重視） / A Clean（落ち着き）
【載せる機能 1〜2】  （例: 荷物配送 / Wi-Fi / 行程プラン / タクシー / チェックインQR）
【言語】            例: 英語主＋日本語 / 英語のみ / 韓国語 / 中国語(簡体・繁体) / タイ語 / 仏語 など自由に（複数可・非ラテン文字はNoto Sansで自動対応）
【前日メモ（任意）】 （現場で拾った定性情報を箇条書きで。ここが精度を上げる）
```

## 記入例
```
【誰に】チェックイン直後の欧米ゲスト
【シナリオ】次の目的地・京都へ荷物を送りたい → ohbagのヤマト手配
【媒体】A4チラシ
【テイスト】B Energetic
【載せる機能】荷物配送 / チェックインQR
【言語】英語主＋日本語
【前日メモ】大きいスーツケースで新幹線移動を面倒がる声が多い。QRを大きく、が刺さりそう
```

## コツ
- **1枚＝1メッセージ**。機能を詰め込みすぎない（迷ったら主役1つ＋補足1つ）。
- ダウンロード導線（QR/ストア）は毎回入れる。
- 出た叩き台に「ここを直して」と会話で微修正できる（例: 見出しをもっと短く／QRを大きく）。
