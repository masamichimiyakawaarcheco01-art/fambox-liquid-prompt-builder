# 新キャラ追加レシピ — ストックにないキャラを自分で作って使う（所要 約5分）

> ohbag Project の Claude は**画像を生成できません**（HTML/SVG描画のみ）。「新しいキャラを作って」と頼むと
> 「ライブラリがない」と返るのはこのためです。新キャラは**このレシピで自分で用意 → 変換 → 貼り付け**れば、
> その日のうちに使えます。宮川さんの作業待ちは不要です。
> ※ 2026-07-13 実地テスト済み（参考画像添付方式でテイスト一致を確認）。

## 手順（3ステップ）

### ① 画像生成AI でキャラを作る（Gemini など）
**⚠️ 最重要：既存キャラの画像を1枚添付してから生成する**（言葉だけではテイストがズレます。実証済み）。
添付する参考画像は `ohbag_style_ref.png`（＝既存キャストのビジネス旅行者）など、ストック済みキャラなら何でもOK。

添付したうえで、下のプロンプトの `[人物の説明]` だけ書き換えて生成：

```
添付画像のキャラクターと完全に同じアートスタイル・同じシリーズとして、新しいキャラクターを1体生成してください。
- 人物: [ここを書き換える。例: 30代の父親と小学生の娘。楽しそうに会話している]
- スタイルの厳守ポイント（添付と揃える）:
  ・マットな粘土（クレイ）質感。ツヤや光沢を出さない
  ・目は開いた小さな黒い点目。口は閉じるか控えめな微笑み（歯を見せない）
  ・やや低頭身で、手足は太めのぽってりした造形
  ・色はくすんだ低彩度（グレイッシュなネイビー・カーキ・ベージュ系）。柄物や高彩度は避ける
- 構図: 全身・立ち姿・少し動きのあるポーズ・正面やや斜め
- 背景: 完全な単色（白）。影は足元に薄く。画像内に文字を入れない
```

### ② 背景を消す（Mac 標準機能・元画質のまま）
- 生成画像をダウンロード → Finder で**右クリック → クイックアクション → 背景を削除**
- 同じ場所に透過PNG（`〇〇 背景を削除.png`）が即生成される。無料・オフライン・**解像度が落ちない**
- ※ Windows の場合の代替: remove.bg（無料版は解像度が落ちる点に注意）や PowerPoint の背景削除

### ③ 変換ツールに通して、チャットに貼る
1. `image-to-snippet.html` をダブルクリックで開く（ブラウザで動く・ネット不要）
2. 透過PNGをドラッグ → 自動で軽量化 → **「スニペットをコピー」**
3. ohbag Project のチャットに貼り付けて、続けてこう書く：
   > ↑この img をキャラとして右側に配置して（object-fit:contain・パネルからはみ出させる）

これで新キャラ入りのチラシ・名刺が出ます。

## よくあるつまずき
| 症状 | 対処 |
|---|---|
| 生成キャラの雰囲気が既存と違う | **参考画像を添付し忘れていないか確認**（最頻出）。添付しても実写調になる場合は「マットな粘土質感」「点目」を強調して再生成 |
| 目が閉じている/歯が見える笑顔になる | プロンプトの「スタイルの厳守ポイント」2行目をそのまま残して再生成 |
| 変換ツールで ⚠️大きめ と出た | 画像の余白が広すぎる可能性。被写体ぎりぎりでトリミングして再変換 |
| 貼ったのに画像が出ない | スニペットが途中で切れている。テキスト全体（`<img` から `>` まで）をもう一度コピペ |

## 良いキャラができたら（定番化）
現場で好評だったキャラは宮川さんに透過PNGを送ってください。正式ストック（ナレッジ）に昇格させ、
以降は誰でも「〇〇のキャラで」と言うだけで使えるようになります。
