## 収集メモ
- **3件確保**（シード fintech / 明るい系 healthcare / ダーク系 transport）。いずれもフルページ多セクションで抽出情報量が多い。
- **配色レンジを確保**: 明るい(白基調)・暗い(ダーク)・1アクセント(赤/レッドオレンジ) の3型 → SYSTEM.md の color トークンが安定。
- 任意の補完: 価格表 / フォーム / サインアップ画面が見えるとコンポーネント網羅が上がる。
