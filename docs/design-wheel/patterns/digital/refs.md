## 収集メモ
- **3件＋遡及候補1件 = Systematize 水準に到達**。型のレンジも確保（ポートフォリオ印刷物 / 環境サイネージ / Web UI）。
- 補完すると強い: ①プロダクト3Dレンダー主役の LP ②ダッシュボード/アプリ UI ③ダークモードのテック系サイト。
- 共通項メモ: 文字×オブジェクトの前後深度は sporty/gradient とも共有する横断技法（SYSTEM 起草時に「深度ライブラリ」として共通化候補）。
- digital の輪郭が見えてきた: **「計測・規格・精密」を感じさせる語彙**（計測線/モノスペース/bento/数字主役）＋彩度は図形・被写体に限定。corporate（余白の信頼）/ sporty（運動量）との差分が明確。
