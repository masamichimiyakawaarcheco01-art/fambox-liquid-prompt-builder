## 1. Identity
- **パターン名**: sporty
- **一言定義**: アクション写真が主役。特大コンデンスタイポを被写体と前後に重ねる「深度」と、1ビビッドアクセント・色帯・統計数値で**速度と熱量**を作る様式。corporate が「余白の信頼」なら sporty は「運動量の説得」。

## 2. Color
**写真の色が主、UI 色は脇役**。アクセントは1作品に1ビビッドのみ（エナジー系から選ぶ）。

| 役割 | 値 | 用途 |
|---|---|---|
| bg | #FFFFFF | 画面背景（写真を立たせる白） |
| surface | #F4F5F6 | カード/面（薄グレー） |
| ink | #0E0E12 | 見出し・主テキスト |
| ink-muted | #8A8A90 | 副テキスト |
| accent | #FF4D1F | 色帯・CTA・数値強調（**エナジーオレンジ**） |
| accent-alt | #2E6BE6 | 代替アクセント（コートブルー / 1作品ではどちらか一方のみ） |
| line | #ECECEE | 罫線（設計図的グリッド下地にも使う） |

**ゾーニング規則**: ヒーロー=フルブリード写真（または写真プレースホルダ）／本文セクション=白 bg＋薄グレーカード／accent は「色帯（横断バンド）・数値・CTA」の運動表現に限定。**デュオトーン処理**（写真の一部を accent で反転）は許可される唯一の大面積アクセント。

## 3. Type
- **書体方針**: コンデンス寄りの極太 sans を **uppercase** で（Inter Bold→人間仕上げで Archivo Expanded 等は使わない: [[feedback_fam_typography]] 留意。FAM 適用時は Poppins ExtraBold）。日本語は太ゴシック。
- **6段スケール（PC）**: 飾り/Display 88px(w800・uppercase) / 大H1 56px(w800) / H2 32px(w700) / H3 20px(w600) / Body 14px(w400) / Small 11px(w600・uppercase・letter-spacing .1em)
- **ジャンプ率**: **超高**（Display 88 ÷ Body 14 ≒ 6.3x）。corporate より一段激しく。
- **行間**: 見出し 0.95–1.05（詰める）／ 本文 1.6
- **深度規則**: Display は写真と**前後に重ねる**（文字の一部を被写体の奥に潜らせる）— sporty 最大の識別子。

## 4. Layout
- **グリッド**: 12カラム / ガター 24px / ヒーローはフルブリード（マージン 0）、本文セクションは外マージン 80px。
- **整数比**: ヒーロー = 全幅 × 60–70vh。統計・カード列は 1:1:1。
- **余白 S/M/L（等比 2x）**: S 16px / M 32px / L 64px。
- **動勢**: 写真カードの **±3〜6° 回転**・斜め配置・色帯の画面横断を許可（corporate では禁止の遊び）。

## 5. Components
| 要素 | 角丸 | 影 | 状態 |
|---|---|---|---|
| ボタン（pill） | 999px | なし | accent 塗り or 白塗り+ink 文字／hover 拡大 1.05 |
| 統計カード | 16–24px | なし | 特大数値(H1)＋小ラベル(Small)。"18K+" "100%" 型 |
| 写真カード | 16–24px | 微細 | ±3〜6° 回転可。hover で回転 0° に戻す |
| 色帯（バンド） | 0 | なし | accent 単色。写真の前後を貫通させ深度を作る |
| 番号バッジ | — | — | #01 形式・accent 色 |
| グリッド下地 | — | — | line 色の細線・同心円（設計図/計測の気配） |

## 6. Motion
- **速度**: 0.2s（corporate より速い）
- **イージング**: cubic-bezier(.16,1,.3,1)（強い ease-out = 初速が速い）

## 7. DO / DON'T
- ✅ DO: アクション写真をフルブリードで主役に／Display を被写体と前後に重ねる／1ビビッドアクセント＋デュオトーン／統計数値を特大で／色帯の横断／±3〜6° の回転・斜め／薄いグリッド下地で「計測」の気配。
- ❌ DON'T: 写真を小さく恐る恐る置く／アクセント2色以上の同時使用／パステル・装飾セリフ／全要素を水平垂直に整列させて静止させる（corporate 化）／文字を常に写真の手前に置く（深度が死ぬ）／テキスト過密。
