## 1. モード選択

| モード | 用途 | 一言 |

## 2. タイポトークン（モード別・実測）

地：日本語 = Hiragino Sans（W4〜W8 を階層化）／英字・数字 = Poppins。
**構築時は Hiragino/F910/YuMincho が MCP 未導入 → Noto Sans JP（JA）+ Poppins（EN）代替。最終は Mac で差し替え。**

共通スケール（pt）：`32 / 28 / 24 / 20 / 16 / 14 / 12 / 11 / 10`。ジャンプ率 1.2 / 1.5 / 2.0。小ジャンプ時はタイトルを太く。

| ロール | サイズ | 行間 | トラッキング |
|---|---|---|---|
| Display/Hero見出し | 28-32 | 150% | -3〜-4% |
| セクション大見出し | 20 | 120-125% | -2% |
| サブ/カラム見出し | 14-16 | 125-140% | -2〜0 |
| 本文 | 10-11 | **170%（標準）** | +1% |
| キャプション/注記 | 8-9 | 140-150% | +1% |
| 英字 eyebrow ラベル | 11 | — | +3% |

モード固有の表示書体：
- **A**：実績数字 = **Inter Extra Bold Italic 72**（斜体特大スタッツ）。見出し Hiragino W7、本文 W5。
- **B**：効果音/特大 = **F910-Shin-comic-tai 108/42/40**、英字 = **Poppins Bold Italic**、和文パンチ = **Hiragino W8**。
- **C**：見出し = Hiragino **W8** / Poppins SemiBold、本文 W5/W6。コミック書体は使わない。

**斜体＝エネルギー**（スポーツ躍動はイタリックで）。数字・実績・価格・栄養価は特大スタッツ化。見出しに Bold700 は避け Semibold/W7 まで（Manga の W8 は例外）。

**色は役割予約**（彩度は action/signal に、surface は静かに）。1色=1役割を全ページ一貫。彩度高ベタ2面を隣接させない。

## 4. スペーシング/グリッド

- A4 = 595×842pt（A1大判 = 1820×2570）。内側パディング **32 基準**（情報多め32 / ゆとり48）。
- 余白は **8の倍数**：`4/8/12/16/20/24/32/40/56`（あえて崩す例外は強調目的のみ）。
- グリッド：12 カラム基準（2col=6+6 / 3col=4+4+4）。本文幅は利用幅の 70-80%。
- 箱の概念：パディング・要素間 gap・背景の内側余白を常に「箱に何が入っているか」で設計。

## 5. 装飾語彙

- 全モード：**背景の面（帯）でゾーニング**（濃面=impact／淡面=reading）、図版は大きく・重ねて（境界ブリッジ）、英字 eyebrow ラベル、淡グラデで奥行き、線アクセント（オレンジ罫）。
- **A**：明暗ページ混在・通し番号（右下オレンジ）・三角コーナー・「+」マーク・大図＋2-3カラム。
- **B**：効果音（F910 特大・斜め）・斜めコマ割り（黒縁・対角）・吹き出し・切り抜き人物・縦組極太。上で掴み→下で整然3カラム着地。
- **C**：2本柱ダイアグラム・コネクタチップ（ダークpill「Solution」）・双方向矢印（育成⇄活用）・写真グリッド・スマホ実機モックアップ・ロゴロックアップ併記。
