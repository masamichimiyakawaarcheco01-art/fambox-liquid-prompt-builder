# FAMBOX チラシ・印刷物 依頼テンプレート（誰でも版）

> **これは何？** このテンプレに記入して Claude（AI）に渡すと、**70%完成のチラシ叩き台**が Figma に自動で組み上がります。デザインの知識がなくても、伝え方さえ揃えば AI が「型」に沿って作ります。残り30%（フォント・写真・微調整）はデザイナー or Mac で仕上げます。

---

## 使い方（3ステップ）

1. **下の「記入シート」を埋める**（埋まっている項目だけでもOK）
2. **Claude に貼って「fambox-flyer-builder スキルでチラシを作って」と頼む**（参照したい既存チラシの画像があれば一緒に渡すと精度が上がります）
3. **Figma に出てきた叩き台を確認 → 直したい所を日本語で伝える**（例：「監修者をもっと大きく」「クーポンを目立たせて」）

---

## 記入シート（コピーして埋める）

```
■ 媒体：（例）A4チラシ表裏 / ポスター / パンフレット
■ 誰に向けて：（例）個人アスリート・家庭 / 実業団・チーム（B2B）
■ 目的（一番伝えたいこと）：（例）世界観で惹きつけたい / 信頼を伝えたい / お得さで再購入を促したい
■ テイスト：A 雑誌風(落ち着き) / B マンガ風(熱量MAX) / C 提案資料風(図解・信頼) ← どれか
■ 載せる情報と優先度（大=大きく / 中=読ませる / 小=必要な人だけ）：
   - 大：
   - 中：
   - 小：
   - 裏に回す：
■ 確定情報（あれば）：クーポンコード / 割引 / URL / 電話 / 監修者名 など
■ 参照したい既存チラシ：（Figmaの該当アートボード名 or 画像）
```

## AI がやること / 人がやること

| AI（自動・70%） | 人（仕上げ・30%） |
|---|---|
| レイアウト（優先度で面積配分）／背景の色分け／文字の大きさ・行間／英字ラベル／グレーboxで写真枠／QR配置／構図の自己チェック | 日本語ブランドフォント適用（Mac）／実写真の選定・切り抜き／最終の美的微調整 |

## 良い依頼のコツ（精度が上がる3つ）
1. **「一番大きく見せたいもの」を1つ決める**（これで構図が決まります）
2. **参照したい既存チラシの画像を渡す**（言葉より画像が最強の指示）
3. **「今だけ」「最高の」など煽り言葉は避ける**（FAMBOX のトーンに合いません）

---

## 仕組みの裏側（興味があれば）
このテンプレは `fambox-flyer-builder` という Claude スキルにつながっています。スキルは過去の制作物から抽出した **3テイストモード・配色・文字ルール・レイアウトの型**を内蔵し、**新しい学びが出るたびに自動で賢くなる**ように作られています（デザインホイール＝Flywheel の Generate 層）。
