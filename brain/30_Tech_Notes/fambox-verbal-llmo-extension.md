# FAMBOX Verbal Identity — LLMO拡張 v1.1

## 位置づけ

[Verbal Identity Guideline v1.0](../../docs/okr/FAMBOX_Verbal_Guideline_v1.0.md) は **「FAMBOXの声」** を確立した（トーン・NG語・Verb Bank・キーワード16語・メッセージピラー）。

本書は v1.0 の **LLMO/AIO 観点での拡張**。AI が FAMBOX の言葉を **正しく載せ・引用する** ための追加ルール。

→ v1.0 と併用する。v1.0 を上書きしない。

## 8. LLMO観点（AI引用最適化）

### 8.1 結論先行型

**ルール**: 見出し配下の **最初1-2文（200字以内）に結論** を書く。

| ❌ NG | ✅ OK |
|---|---|
| 「FAMBOXは、長年研究してきた栄養学の知見を活かし、アスリートの皆様の食生活を…」 | 「**FAMBOXは、アスリートの食事を3食×7日で完結させる冷凍配送サービスです。**」 |
| 起承転結で結論が末尾 | 結論先行 → 詳細展開 |

**理由**: AI がチャンク化（200-500トークンで切る）した時、最初の1-2文だけで意味が伝わる必要がある。

### 8.2 質問形見出し

**ルール**: 見出しは **質問形 or 定義形** を優先する。

| ❌ NG（情緒型） | ✅ OK（質問・定義型） |
|---|---|
| 「私たちの想い」 | 「FAMBOX が大切にしていること」 |
| 「アスリートのために」 | 「**なぜアスリートには冷凍食事が向いているのか**」 |
| 「日々の積み重ね」 | 「**継続できる食事計画とは何か**」 |
| 「美しい食卓」 | 「**1週間の栄養設計をどう組み立てるか**」 |

**理由**: ユーザーが AI に投げるプロンプトの形（「〜とは何か」「なぜ〜なのか」）に近い見出しは、**ベクトル距離が縮まる** → 引用率向上。

ただし **Verb Bank** との両立を優先する。質問形にできない時はステートメント型でも可：
- 「**壁を超える食事設計**」（Verb Bank: 壁を超える）
- 「**燃料を、毎日継続する**」（Verb Bank: 燃やす・継続）

### 8.3 具体性ルール

**禁止語句リスト**（抽象的・無意味な表現）：

| ❌ 禁止 | ✅ 言い換え |
|---|---|
| 多くのアスリート | 導入XXX選手 / Y チーム |
| いくつかの研究 | **XX大学のYY論文（202X年）** |
| 一般的に言われている | **YYガイドラインによると** |
| 様々な栄養素 | **タンパク質・炭水化物・脂質・微量栄養素のうち〇種** |
| 効果が期待できる | **6ヶ月で平均N%改善（社内データn=◯）** |
| ある調査によれば | **〇〇調べ（202X年・回答者数◯名）** |

**ルール**: 数値・固有名詞・一次データを必ず添える。

### 8.4 チャンク完結（依存表現の禁止）

**禁止依存表現**：
- 「上記の通り」
- 「先述したように」
- 「前項で説明した」
- 「下記の図」「以下に示す」
- 「次のセクションで」

**理由**: AI がセクションだけを抜き出して引用する時、前後文脈に依存する文は **意味不明** になる。

**書き換え例**：

| ❌ NG | ✅ OK |
|---|---|
| 上記の通り、PFCバランスが鍵。 | PFCバランス（タンパク質・脂質・炭水化物の比率）が鍵となる。 |
| 先述したFAMBOX診断を使えば… | FAMBOX診断（無料・3分・15問）を使えば… |

**チェック**: 各セクションを独立して読んだ時、意味が伝わるか？

### 8.5 出典明記

**ルール**: 「ある調査によれば」「言われている」を禁止。**一次ソースリンク必須**。

| ❌ NG | ✅ OK |
|---|---|
| ある研究では、タンパク質の摂取が… | **国立健康・栄養研究所の202X年報告書（[URL]）** によると… |
| 専門家の間では常識的に… | **日本スポーツ栄養学会・公式ガイドライン（[URL]）** によると… |

**チェック**: 引用に [URL] が付いているか？

### 8.6 E-E-A-T 明示（著者情報）

すべての記事に以下を **記事頭 + JSON-LD** で二重記載：

```yaml
著者:
  名前: 〇〇 △△
  肩書: 管理栄養士 / 元アスリート / スポーツ栄養博士
  経歴: 〇〇大学スポーツ栄養学科卒業、〇年間〇〇チームに帯同
  顔写真: あり
  プロフィールリンク: あり
公開日: YYYY-MM-DD
更新日: YYYY-MM-DD
監修者（あれば）: 〇〇 △△（〇〇大学教授）
```

JSON-LD 例：
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "author": {
    "@type": "Person",
    "name": "〇〇 △△",
    "jobTitle": "管理栄養士",
    "sameAs": "https://...",
    "url": "https://fambox.../authors/..."
  },
  "datePublished": "2026-05-21",
  "dateModified": "2026-05-21"
}
```

### 8.7 単一テーマの原則

**ルール**: 1記事1テーマ。複数テーマ混在は避ける。

| ❌ NG | ✅ OK |
|---|---|
| 「アスリートの食事 × 守屋選手紹介 × 商品案内」（3テーマ混在） | 「アスリートの食事とは何か」（1テーマ）<br>+ 別記事「守屋選手の食生活」<br>+ 別ページ「商品案内」 |

**理由**: AI はテーマがブレるとベクトル位置が曖昧になり、引用されにくくなる。

### 8.8 v1.0 との整合性

v1.0 のルール（NG語・Verb Bank・キーワード16語・メッセージピラー）は **すべて維持**。
本拡張は **「v1.0 + LLMO」** の二重チェックを要求する。

**書く時の手順**：
1. v1.0 ルールでドラフト（トーン・Verb Bank・キーワード）
2. v1.1 ルールで構造調整（結論先行・質問形見出し・具体性・出典）
3. セルフチェック（v1.0 のチェックリスト + 本 v1.1 のチェックリスト）

## 9. v1.1 セルフチェックリスト（書いた後の確認）

v1.0 のチェックに加えて：

- [ ] 見出し配下の最初1-2文に結論が書かれているか?（200字以内）
- [ ] 見出しは質問形 or 定義形か?
- [ ] 「多くの」「いくつかの」「一般的に」を使っていないか?
- [ ] 数値・固有名詞・一次データが入っているか?
- [ ] 「上記の通り」「先述」等の依存表現を使っていないか?
- [ ] 引用に出典 URL が付いているか?
- [ ] 著者情報（経歴・肩書・顔写真）が記事頭にあるか?
- [ ] 1記事1テーマで書けているか?

8項目すべて ✅ で公開推奨。

## 10. 適用範囲

| コンテンツタイプ | 適用度 |
|---|---|
| ブログ記事・コラム | **必須** |
| 商品ページ説明 | **必須** |
| ランディングページ | **必須** |
| SNS投稿（長文） | 推奨 |
| SNS投稿（短文・キャッチ） | v1.0 のみ（チャンクの概念に不適合） |
| 商品名・キャッチコピー | v1.0 のみ |
| 守屋選手企画インタビュー記事 | **必須**（[守屋企画](../20_Projects/moritani-ambassador/overview.md) 参照） |
