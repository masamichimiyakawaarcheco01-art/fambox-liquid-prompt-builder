# 撮影・インタビュー文字起こしツール選定

## 目的

守屋選手企画（[20_Projects/moritani-ambassador](../20_Projects/moritani-ambassador/overview.md)）の **6月撮影 → 7月公開** のタイムラインで、インタビュー文字起こしを **自動化** して時間を短縮する。

人手だと60分インタビューで2〜3時間かかる作業を **15分以下** に。

## 要件

### 必須
- ✅ **日本語の精度** （守屋選手のインタビューは日本語）
- ✅ **話者分離**（インタビュアー vs 守屋選手）
- ✅ **タイムスタンプ付き** 出力
- ✅ **Markdown / SRT エクスポート**
- ✅ **長時間音声対応**（60〜90分）

### あれば嬉しい
- ⭕ 動画ファイル直接対応（音声抽出不要）
- ⭕ 専門用語学習（ラグビー・栄養用語）
- ⭕ API 連携可能（自動ワークフロー化）
- ⭕ プライバシー保護（個人情報・契約上の制約）

### 制約
- ⚠️ 守屋選手は **個人契約**（チームロゴ・所属を含むセンシティブ情報あり）
- ⚠️ 公開前の素材を扱う → **クラウド保存先・データ保持期間** が重要

## 推奨：**ハイブリッド構成**

### 一次処理：MacWhisper（ローカル）
- **理由**:
  - センシティブ素材を **Mac内のみで処理** → クライアント・個人契約のリスクゼロ
  - 買切¥3,800 = 月額負担なし
  - Whisper large-v3 ローカル実行で日本語精度十分
  - macOS ネイティブで使いやすい

### 仕上げ処理：Notta or CLOVA Note（話者分離 + 確認用）
- **理由**:
  - 話者分離はWhisperでは弱い → 仕上げで補正
  - Webブラウザで再生・修正がしやすい
  - 公開素材化前の最終チェック用

### 自動ワークフロー化（応用）
将来的に `projects/analytics/` のように launchd で：
- 撮影フォルダに動画が追加されたら → MacWhisper 起動 → 文字起こし → Markdown化 → brain/20_Projects/moritani-ambassador/transcripts/ に保存

## 文字起こし後の二次処理（Claude API 統合）

文字起こしだけでなく、**「言わせたい結論」整合チェック** にClaude APIを使う：

```
【守屋選手企画のインタビュー文字起こし】
{transcript}

【FAM側が言わせたい結論（3点）】
1. アスリートの土台は食である
2. ラグビー界は栄養への投資が遅れている
3. FAMが守屋選手の実体験で機能している

【依頼】
1. 上記3点が文字起こしに含まれているか判定
2. 含まれている場合、該当箇所を引用
3. 不足している場合、追加質問の提案
4. SNSショート動画に切り出せる「30秒以内のハイライト」を5箇所抽出
5. 営業チラシに使える「決め台詞」を3つ抽出
```

→ これで文字起こしから記事ドラフト・SNS素材・営業資料の **3つの成果物** が一気に生成できる。

## ガードレール

- **クラウド保存禁止 → ローカル処理優先**（MacWhisper）
- **公開前素材の取扱い**: 文字起こしファイルにも `[CONFIDENTIAL]` ラベル
- **クライアント承認前の引用禁止**: AIが生成した「決め台詞」案は必ず守屋選手・エージェント承認
- **専門用語誤認**: ラグビー・栄養用語の誤変換は手動で修正必須

## 期待される効果

| 観点 | Before | After |
|---|---|---|
| 60分インタビュー文字起こし | 2〜3時間（手作業） | **15分**（MacWhisper処理 + 軽量補正） |
| 話者分離 | 手動で「A:」「B:」付与 | 仕上げツールで自動 |
| 「言わせたい結論」整合チェック | 手動で全文読み返し | Claude APIで自動チェック |
| SNS素材切り出し候補 | 手動でハイライト抽出 | AIで候補提示 → 選別のみ |
