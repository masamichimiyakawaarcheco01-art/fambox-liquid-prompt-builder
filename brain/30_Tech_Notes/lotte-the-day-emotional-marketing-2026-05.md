# ロッテ THE DAY — 「機能」から「情感」への軸シフト

## 主な主張

> **「安心・安全」（機能軸）から「気持ちアガる」（情感軸）へ**。
> ロッテは飲料カテゴリで、ミネラルウォーターを **デイリー・プレミアム** として再ポジショニング。
> 「饒舌ではなくムードで伝える」クリエイティブが鍵。

## 衝撃の数字

| 指標 | 値 |
|---|---|
| 日本のミネラルウォーター市場 | **約4,500億円** |
| Z世代の「好きな飲料カテゴリ」 | **水が1位** |
| CM尺 | 15秒 |
| 商品発売 | 2025年9月 |
| CM公開 | 2026年5月4日 |

## コア10ポイント

1. **市場機会** — 水が4,500億円市場でZ世代支持を獲得
2. **差別化軸** — 「安心・安全」から「気持ちアガる」情感へ
3. **ブランド資産の転用** — お菓子・アイスの「こころ動かす体験」を飲料に拡張
4. **キャスティング** — 加藤小夏の「無邪気さ」が共感の核
5. **クリエイティブ手法** — 「饒舌ではなくムード」で記録する
6. **感覚表現** — 冷えたアルミ缶の質感・晴れやかな表情で情動喚起
7. **販路 × メッセージ** — 流通拡大とともに生活密着型コピーへ進化
8. **マルチメディア** — CM + ビデオポッドキャスト「THE DAY ROOM」併行
9. **ポジショニング** — 「何でもない一日を最高の一日へ」
10. **CD体制** — TaiTan による情感統括

## 重要引用

> 「デイリープレミアムウォーターとは何か。単なる商品広告ではなく、その新しい概念を **できるだけ饒舌にならずに伝えることを意識** しました」
> — TaiTan（クリエイティブディレクター）

## FAMBOX への直接応用

### A. 「機能軸→情感軸」のシフト

| 旧アプローチ | 新アプローチ（THE DAY流） |
|---|---|
| 「PFCバランスが整った冷凍食」 | 「**冷凍食から、冷えた筋肉へ。回復の瞬間が変わる**」 |
| 栄養成分の数値訴求 | アスリートの **「気持ちアガる瞬間」** をムードで切り取る |
| カロリー比較表 | 食事後の **晴れやかな表情** にフォーカス |

### B. 守屋選手企画 × THE DAY 手法

**「FAMBOX × 守屋 — 毎日が最高のトレーニングデー」キャンペーン案**：

| 要素 | 仕様 |
|---|---|
| キャッチコピー | 「冷凍食から、冷えた筋肉へ。」（饒舌でないムード型） |
| キャスティング演出 | 試合シーンではなく **食事後の表情** にフォーカス |
| 表現手法 | レンジ加熱時の湯気・一口目の集中力 等の **感覚表現** |
| 尺 | 15秒（THE DAY と同じ） |
| 付帯メディア | ポッドキャスト「**守屋が語る、最高の食事タイミング**」（THE DAY ROOM 同形式） |

### C. パッケージ色分け戦略

THE DAY の「ナチュラル=青 / スパークリング=赤」を参考に、FAMBOX も用途別カラーコード：

| 用途 | 色 |
|---|---|
| 筋肉回復（高タンパク） | 赤 |
| 持久力（高炭水化物） | 青 |
| 集中力（バランス） | 黒 |
| 試合前（軽量） | グレー |

### D. Verbal Identity v1.0 との接続

FAMBOX Verbal Identity の **「冷静で情熱的」** トーンは、THE DAY の「饒舌ではなくムード」と完全に整合：
- **冷静さ** = 饒舌でない、過剰装飾なし
- **情熱** = 一口目の集中力・晴れやかな表情で表現
- **断定** = 「変わる」と言い切る

→ 既存トーンに「**感覚表現の重視**」を追加する補強。

## Animation Library との接続

[Animation Library v0.1](../../brand/fambox/animation-library-v0.1.md) の各パターンを **「ムード」表現** として再解釈：

| パターン | ムード表現としての解釈 |
|---|---|
| Morph Blob | 「内なるエネルギーの脈動」= 試合前の集中の表現 |
| FUEL（不規則火花） | 「一口目の覚醒」= 食事直後の身体反応の可視化 |
| Elastic Bars | 「筋肉の動的緊張」= 触れたら反応する身体の感覚 |

→ THE DAY 流の「感覚表現」を FAMBOX で実装する時、アニメーションが **言葉の代わり** になる。

## ARCHECO デザイン業務への示唆

### 既存業務への適用
- LP制作で「機能訴求パート」と「情感訴求パート」を明確に分離
- 商品ページのヒーローは **「数値の前にムード」** を優先
- SNS素材は **「饒舌ではない一瞬」** を切り取る方針に転換

### 競合差別化
> 大手代理店が「機能訴求のテンプレ」を回している間に、ARCHECO は **「情感訴求のクラフトマン」** として差別化できる。

これは [尾原Ep2](obara-ai-agent-era-ep2.md) の「文脈の濃度」が競争優位という主張と整合する。
