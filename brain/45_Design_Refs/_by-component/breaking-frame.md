# breaking-frame — Design References

## ブランド意義（FAMBOX軸2）
軸2「動の発火」の **構造的隠喩**：
- 砂塵の飛散（Nike Pin） = 物理的隠喩
- フレームブレイク（このピン） = 構造的隠喩
- 両者は同じ「発火」を異なる比喩で語る
