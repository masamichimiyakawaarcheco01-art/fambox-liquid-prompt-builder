# 枠を踏み越える — レイヤー構造による「一歩踏み出す」表現

## なぜ保存したか

> 長方形の枠の上のレイヤーに人物が配置されていることで、
> **一歩踏み出したことを平面な画像でありながら立体的に表現** しているところが魅力。
> **リフレーミングのメタファー** として活用できそう。

→ 軸2「動の発火」のNike Pin（砂塵=発火の火種）に並ぶ、**もう一つのキャノニカルな技法**。
→ 「一歩踏み出す瞬間」を **レイヤー構造（=次元の跨ぎ）** で表現する手法。

## ブランドDNA軸での位置づけ

**軸2: 動の発火 — Ignition × Calm Resolve** の **動側（火花〜発火）の5件目**。
これまでの軸2 refs と比較して新しい技法軸：

| ref | 「一歩踏み出す」を何で表現 |
|---|---|
| ACW Sport Poster | グラフィック・人物のステートメント |
| アスリート躍動的フォト | 動作中の瞬間捕捉 |
| Nike First Step Ignition ★canonical | **砂塵の飛散**（粒子=発火の火種） |
| **このピン ★new canonical候補** | **レイヤー構造（枠を踏み越える）** |
| Baltatzis blur-mask | 集中・Calm Resolve |

→ 軸2の視覚語彙が **物理的隠喩（砂塵）** だけでなく **構造的隠喩（フレームブレイク）** にも広がった。

## 注目ポイント
- **レイヤー構造**: 長方形の枠 → その上に人物を配置 → 平面が立体的に立ち上がる
- **2Dで3Dを語る**: 静止画でありながら **空間的な前進**（前後関係）を生む
- **リフレーミング**: 「枠の中」から「枠の外」へ踏み出す = 既成概念の超越メタファー
- **動的ポーズ**: スケートボードでの前進 = 文字通りの「一歩踏み出す」
- **配色**: オレンジの暖色 → エネルギー・若さ・温度感
- **テキスト**: "inspire inspire" の繰り返し = **発火の連鎖** を言語的に表現
- **広告文脈**: Fashion Creative Ads = 行動を促す視覚言語の研究素材

## ARCHECO/FAMBOXでの応用案

### 1. リフレーミング技法 — FAMBOXのキービジュアル
**「枠の中の食事」から「枠を超えた身体」へ** という視覚メタファー：
- 食事プレート（枠）の上に、踏み出すアスリートを配置
- FAMBOX（容器）から、活動的な身体が立ち上がる構図
- 「日常の食事を超える経験」を1画面で示せる

### 2. 守屋選手企画への応用
- **キービジュアル候補**: 練習場（枠）の上に、踏み出す守屋選手を重ねる構図
- **SNSショート**: 静止フレーム → 人物が枠を踏み越えるアニメーション
- **記事サムネイル**: 「現状の枠を超える」というメッセージを構造で表現

### 3. FAMBOX診断ウィザードでの応用
- **質問→結果遷移**: 質問の枠から、推奨食事の人物（あるいはアスリート）が立ち上がる演出
- **進捗の表現**: 各ステップで枠を1つずつ越えていくアニメーション

### 4. Liquid/CSS実装方針
- **`z-index` + `transform: translate`** で枠の上に人物を配置
- **`mask`** で人物の一部だけ枠の外に出す
- **`box-shadow`** で立体感（人物の影が枠の外側に落ちる）
- **スクロール連動アニメーション**: スクロール量に応じて人物が枠から押し出される

### 5. 軸2の視覚語彙の拡張
これまで軸2の主要技法は：
- 砂塵の飛散（Nike）
- ぼかし×マスク（Baltatzis）

そこに **「フレームブレイク（リフレーミング）」** を追加：
- 砂塵 = 物理的な発火の証拠
- フレームブレイク = **構造的な発火の証拠**（既存の枠を超える）

両者は同じ「発火」を異なる比喩で語っている。

## 他軸との合成可能性

- **軸1 × 軸2 合成**: 化学式風の概念図（軸1の枠）の中から、踏み出す人物（軸2）が立ち上がる
- **軸2 × 軸3候補 合成**: 砂塵（発火）の積み重ねが氷の結晶（努力の結晶）として枠の外に立ち現れる
