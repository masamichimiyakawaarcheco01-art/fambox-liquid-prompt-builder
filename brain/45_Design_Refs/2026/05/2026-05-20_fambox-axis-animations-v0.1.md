# FAMBOX Animation Library v0.1 — 軸対応アニメーション5パターン

## なぜ保存したか

FAMBOX ブランドDNA軸（軸1/2/3）を、**実装可能なアニメーションパターン** として確立した最初のバージョン。今後の全制作物の **共通言語** として使う候補。

## 状態
- v0.1 候補ステータス
- デモHTML実装済
- 須藤さん承認待ち

## 構成

| # | パターン | 軸 |
|---|---|---|
| 01 | Dot Hover Cards | 軸1 適用型 |
| 02 | Pattern Cards (リズム付) | 軸1 静の信頼 |
| 03a | SCIENCE (ナフタレン+データフロー) | 軸1 概念図型 |
| 03b | FUEL (不規則火花) | 軸2 動の発火 |
| 03c | CARRY (多層+ローズ曲線) | 軸3 候補 努力の結晶 |
| 04 | Elastic Bars (スプリング物理) | 軸2 火花（インタラクション） |
| 05 | Morph Blob (Perlin) | 軸2 連続性 |

## 重要な原則

1. **意味先行** — アニメは装飾ではなく、メッセージの運搬手段
2. **物理的自然さ** — 機械的イージングを避け、バネ物理を使う
3. **不規則性の許容** — 単調な円軌道や完全同期は避ける
4. **継続の表現** — 「目立たないが止まらない」動きで継続性を示す
