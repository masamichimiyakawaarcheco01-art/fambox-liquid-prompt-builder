# 代官山青果店 — モノトーンのラボ的レイアウト

## なぜ保存したか

> 若干散らばって見えるが、**ラボ的なレイアウトとして参考になる**。
> **幾何学的な円の画像** と **シンプルな線**、**ウェイト別の文字の羅列** はデザインの世界観表現の参考になる。

→ 軸1（静の信頼 — Lab × Editorial）の **食品ドメインへの適用例** として直接参考になる。

## ブランドDNA軸での位置づけ

**軸1: 静の信頼 — Lab × Editorial** の3件目。前2件と異なる重要点：

| ref | 内容 | 軸1のどの側面か |
|---|---|---|
| WorRC | 非営利のブランドガイドライン | 組織アイデンティティの編集表現 |
| 化学式概念図 | 栄養科学の概念図 | データ・概念の科学的視覚化 |
| **代官山青果店** | **食品店のWebサイト** | **食品ドメインへのLab×Editorialの適用** |

→ FAMBOXは「食」のブランドであるため、**この3件目の応用文脈が最も近い**。

## 注目ポイント
- **幾何学的な円**: 食品（野菜・果物）を円形にトリミング → ラボの試料・分子モデル的な見せ方
- **シンプルな線**: 装飾を排した補助線・区切り線
- **ウェイト別タイポ**: 異なるウェイトでヒエラルキーを構築（読ませるエディトリアル）
- **若干散らばった配置**: グリッドに従いながらも、機械的整列を避ける = **「整理された散らばり」**
- **モノトーン**: 黒・白・グレーで素材（食品）を引き立てる
- **抑制されたトーン**: 高級感・落ち着き

## ARCHECO/FAMBOXでの応用案

### 1. FAMBOX 商品ページ・カタログ
- 食材・メニューを **円形クロップ** で並べる → 試料的な見せ方
- 「ほうれん草、鶏胸肉、玄米...」を **均一な円形フレーム** で揃え、栄養成分を別レイヤーで重ねる
- ウェイト別タイポで「商品名（重）/ 栄養素（中）/ 説明（軽）」のヒエラルキー

### 2. FAMBOX診断ウィザード結果
- 結果ページで「あなたに必要な栄養素」を **化学式概念図 + 食材の円形画像** で示す
- 軸1×3件のリファレンス（WorRC + 化学式 + 代官山青果店）の **合成適用** が可能

### 3. 守屋選手企画コンテンツ
- ラグビー選手向けの食事紹介を、ストイックなラボ的レイアウトで見せる
- 「PFCバランス」「リカバリー食材」を円形画像 + ウェイト階層で構成
- アスリート向け = 真面目で、装飾が少ない方が説得力がある

### 4. Liquid実装方針
- Shopifyテーマで `image_url` を円形マスクで表示するセクション
- 商品画像を `border-radius: 50%` + `object-fit: cover` で統一
- メタフィールドで「栄養成分」を取り、ウェイト別タイポで階層表示

## 軸1の進化（3件目で見えてきた表現幅）

軸1（静の信頼 — Lab × Editorial）は以下の **3つの表現タイプ** を内包する：

1. **ガイドライン型**（WorRC）: 組織アイデンティティの編集
2. **概念図型**（化学式）: データ・概念の科学的視覚化
3. **適用型**（代官山青果店）: 食品ドメインへの実装例

→ FAMBOXのデザインシステム策定時、この3軸を **「役割別」** に使い分ける運用が考えられる。
