# gradient — Design References

## 定義
このスタイルの典型的特徴：
- 粒子（grain）質感を伴うソフトなグラデーション（ベタCSSグラデとは区別）
- 有機的なブロブ形状・浮遊感のあるソフトシャドウ
- UI シェルは白/ニュートラルに徹し、彩色はグラデオブジェクトに集中
- 文字との前後深度（アウトライン文字を奥に / 境界で溶かす）
