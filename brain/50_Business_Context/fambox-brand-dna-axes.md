# FAMBOX ブランドDNA — 視覚的親和性の軸

`brain/45_Design_Refs/` に蓄積された参考から **「これはFAMBOXに近い」と感じた事例** を読み解いて、ブランドDNAの視覚的軸を言語化する。`brand/FAM_brand_DNA_v0.3.md`（Editorial × Lab メタファー確定済）の補足・実証編。

### 軸2: 動の発火 — Ignition × Calm Resolve
**前進の瞬間軸**。次の一歩を踏み出すとき、**火花が集まって炎へと立ち上がる瞬間** と、その中の冷静さを同居させる側面。

軸2は単一表現ではなく、**「火花〜発火」（動）と「Calm Resolve」（静）の二重性** を視覚化する複合軸。下記の2側面 × 表現フォーマットの掛け合わせで展開する：

| 軸2の側面 | 表現要素 | フォーマット | 該当リファレンス |
|---|---|---|---|
| **動側（火花〜発火）** ★canonical | **砂塵・粒子の飛散が「発火の火種」として機能**（物理的隠喩） | 写真（広告） | [Nike First Step Ignition](../45_Design_Refs/2026/04/2026-04-28_nike-first-step-ignition.md) |
| **動側（火花〜発火）** ★canonical2 | **フレームブレイク（枠を踏み越える）= 構造的隠喩** | グラフィック・KV | [枠を踏み越える — レイヤー構造](../45_Design_Refs/2026/05/2026-05-06_skateboard-breaking-frame.md) |
| **動側（火花〜発火）** | 鮮やかな配色・グラフィック・人物・行動への立ち上がり | グラフィック・ポスター | [ACW Sport Poster](../45_Design_Refs/2026/04/2026-04-28_acw-sport-poster.md) |
| **動側（火花〜発火）** | 明暗のはっきりしたコントラスト・動作中の瞬間・リアリティ | 写真・実写 | [アスリートのトレーニング — 躍動的フォト](../45_Design_Refs/2026/04/2026-04-28_athlete-training-photography.md) |
| **静側（Calm Resolve）** | 集中・冷静・揺るがなさ・固まった意思 | モーション（ぼかし×マスク）・ガラス/レンズ光 | [ぼかし×マスクでアスリートの集中を可視化](../45_Design_Refs/2026/04/2026-04-28_baltatzis-blur-mask-focus.md) |

### 軸2の核心的視覚語彙（2件確定）

軸2「発火」を視覚化する **2つの中核的隠喩** が確立した：

#### A. 物理的隠喩 — 「発火の火種 = 粒子飛散」
> **「発火の火種」 = 物理的な砂塵・粒子が飛散する瞬間 (視覚的隠喩)**

Nike First Step Ignition（2026-04-28）から確定。

代替表現（粒子飛散の応用）：
- 栄養素のパーティクル（PFCのアイコンを散らす）
- 食材の断面・粉末・微細な飛散
- 光の粒子・スパーク

#### B. 構造的隠喩 — 「フレームブレイク = リフレーミング」
> **「一歩踏み出す」 = 既存の枠を踏み越えるレイヤー構造 (構造的隠喩)**

Skateboard Breaking Frame（2026-05-06）から確定。

代替表現（フレームブレイクの応用）：
- 食事プレート（枠）→ 踏み出すアスリート
- 質問フォーム（枠）→ 推奨食事の人物
- ステップごとに枠を1つずつ越えていくアニメーション

#### C. 時間的隠喩 ★確定 — 「連続フレームによる段階表現」
> **「一歩踏み出す」を時間軸で段階的に語る（四角形グリッドや連続シーケンス）**

2件のrefで確定：
- [Falling Man Sequence](../45_Design_Refs/2026/05/2026-05-11_falling-man-sequence.md) — 4分割グリッドで落下を分解
- [Basketball プレー集](../45_Design_Refs/2026/05/2026-05-11_basketball-victory-pose.md) — 四角形画像でプレーの幅を見せる

共通項: **「時間軸 × 幾何学的配置（四角形）」**

代替表現（時間軸の応用）：
- 守屋選手の動作分解（蹴る/走る/タックル等を4-6フレームで）
- 守屋選手プレー集（試合・練習・栄養摂取の瞬間を四角形グリッドで）
- FAMBOX診断ジャーニーの4ステップ並列表示
- 栄養代謝の段階（食事→消化→吸収→運動エネルギー）の4分割可視化
- 商品ページの食事バリエーション（朝・昼・夕・補食）

#### 3つの隠喩の使い分け
- **A. 物理的隠喩（粒子）**: 一瞬の決定的瞬間を撮る・描く（**点**）
- **B. 構造的隠喩（フレームブレイク）**: 既成概念の超越（**面**）
- **C. 時間的隠喩（連続フレーム）**: 段階的な前進・ジャーニー（**線**）

軸2の表現が **「点・面・線」** の3次元で揃った（A・B・C すべて2件以上の refs で確定）。

| 要素 | 表現 |
|---|---|
| キーワード | 発火 × 火花 × 情熱 × 燃焼 × **集中** × 静の冷静 × 弛まぬ変化の中の固まった意思 |
| 視覚特徴 | 鮮やかな配色・グラフィック寄り・人物ビジュアル・**ぼかし/マスクによるフォーカス表現**・ガラス/レンズ越しの光的質感 |
| 担う機能 | 行動喚起・アスリート性・「次に動く瞬間」の表現・**集中している瞬間の表現** |
| ニュアンス | 「火花」は散在的・「点火」は確定的すぎるのに対し、「**発火**」は **火花が炎へと立ち上がる動的な変化点**。決まった意思が動き始める瞬間を視覚化する |

### 軸4 候補: 蓄積する負荷 — Accumulating Load（観察中 / 2026-05-21 シード）

**前提状況軸**。軸2「動の発火」の **前段（before）** として機能する。アスリートが日々蓄積する疲労・負荷の物理的可視化。FAMBOX が解決する問題側を表現する素材。

| 要素 | 表現 |
|---|---|
| キーワード | 蓄積 × 負荷 × 重さ × 疲労 × 反復 × 物理的リアリティ × 段ボール / 箱 / 鉛 / 鎖 |
| 視覚特徴 | 3D 物理シミュレーション・落下と堆積・中性的な背景・抑制された配色・単方向の単調な増加 |
| 担う機能 | FAMBOX が解決する問題側（before）の可視化 / アスリート以外の文脈で「日常の負担」も表現可能 |
| 観察元 refs | [Brik — 段ボール箱が落ちて積み上がる 3D シミュレーション](../45_Design_Refs/2026/05/2026-05-21_brik-cardboard-boxes-falling.md)（シード1件目） |
| **昇格条件** | 同方向の refs が **追加2件以上** 集まった時点で正式な「軸4」に昇格 |

時間アーク（更新案）:
```
[軸4候補] 蓄積する負荷 → [軸2] 動の発火 → [軸3候補] 努力の結晶
   before                  moment             outcome
   (問題)                  (解決)             (報酬)
```

→ 軸4 が立つと、FAMBOX のストーリーは **「問題 → 介入 → 解決 → 結果」** の4段アークに進化する。商品ページ・LP・守屋選手企画の構成に直接効く。

### 軸3 候補: 努力の結晶 — Crystallized Effort（観察中）

**継続努力の結果軸**。発火（軸2）の **時間的続き** として、努力・汗・継続が結晶化した姿を視覚化する側面。

| 要素 | 表現 |
|---|---|
| キーワード | 結晶 × 汗の結晶 × 努力の凝縮 × 実績 × 透明感 × 半透明 × 湾曲 × ノイズテクスチャ |
| 視覚特徴 | 氷的素材・透明感・半透明・湾曲した抽象背景・実写×グラフィックのハイブリッド合成 |
| 担う機能 | 達成・継続・成果・実績の表現 |

## 軸の関係性（仮説）

FAMBOX のブランド体験は、**静（土台）→ 動（発火）→ 結晶（成果）** の時間的アークとして組み立てられる可能性：

```
[軸1] 静の信頼      →   [軸2] 動の発火      →   [軸3 候補] 努力の結晶
Lab × Editorial         Ignition × Calm Resolve   Crystallized Effort
   ↑                       ↑                          ↑
 科学・データの土台    一歩踏み出す瞬間          努力が結晶化した姿
（present / 信頼）     （moment / 瞬間）         （outcome / 実績）
   |                       |                          |
   +──── 食事 = アスリートの土台 → 投資 → 次の一歩 → 継続 → 結晶化 ────+
```

アスリート文脈（守屋選手企画など）では、**静のバックボーン（科学・栄養データ）の上に動のキービジュアル（発火）を重ね、結晶化された実績で結ぶ** 3層構成が想定できる。

## 視覚言語の素材候補（軸2: 動の発火 の応用）

軸2「ガラス加工/レンズ越しの光」「ぼかし×マスク」を Web/Liquid で再現する候補技法：
- `filter: blur()` + `mask-image: radial-gradient()` で焦点を絞る表現
- `backdrop-filter: blur()` + 半透明レイヤー重ね（背景のみぼかし、フォアグラウンドはシャープ）
- SVG `feGaussianBlur` + `mask` 要素
- CSS `mix-blend-mode` + グラデーション
- 光線・粒子表現（Canvas / WebGL）
- スクロール連動でフォーカスが動く演出

→ 詳細実装は別途 `30_Tech_Notes/glass-light-techniques.md` 等で検証予定（参考: `feedback_fambox_visual_effects.md` の制限事項に注意 — 輪郭歪み・noise-bloom・グリッチは避ける）

## 判定ガイドライン（新規refs審査用）

新しい参考素材が「FAMBOXに近いか」を判定する際の問い：

1. **静の信頼軸**: 「これは科学・教育・編集的に説得する側にあるか？」
2. **動の発火軸**: 「これは『次の一歩』『心が決まり、火花が炎へと立ち上がる瞬間』を視覚化しているか？」
3. **努力の結晶軸（候補）**: 「これは『継続の結果』『努力が結晶化した姿』『実績の凝縮』を視覚化しているか？」
4. **どの軸でも合致しない場合**: 「FAMBOX中核ではない、サブ表現の素材」として記録（捨てる必要はない）
