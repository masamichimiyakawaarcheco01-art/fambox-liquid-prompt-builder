# 意思決定ログ

## 2026-04-28: ターゲット起用 — 「身近な強豪選手」路線

**決定**: 日本代表トップ選手ではなく、「部活内で一目置かれる強い選手」（守屋選手）を起用。

**根拠**:
- 雲の上の存在ではなく身近な追体験を生む
- 約20年の実体験を入り口に「ラグビー選手あるある」を引き出せる
- 読者層との心理的距離を縮められる

**代替案**:
- 日本代表選手起用 → メッセージは強いが「自分とは違う世界」と受け取られるリスク
- 採用しない理由: 説得対象の心理動線に合わない

## 2026-04-28: インタビュー設計 — 「言わせたい結論」逆算型

**決定**: 通常型（出てきた答えに任せる）ではなく、メッセージを先に決めて逆算する設計。

**根拠**:
- アスリートの回答は予測から外れることが多い（松浦知見）
- 営業活用・チラシ展開を見越した時、メッセージのコアが定まっていないと素材が散る
- 事前ヒアリングで「守屋選手が語れる範囲」を確認できれば本番のロスを最小化

**プロセス**:
1. FAM側で「言わせたい結論」を確定
2. 守屋選手 / エージェントに事前ヒアリング
3. 結論に紐づくエピソードがあるかを確認
4. ある → 質問設計、ない → 当該質問は除外

**リスク**:
- 「やらせ感」が出ないよう、選手自身の言葉で語れる範囲に絞る運用が必須

## 2026-04-28: 撮影制約 — 個人契約ベース

**決定**: トヨタヴェルブリッツのユニフォーム・チームロゴは使用せず、所属の文字表記のみで進める。

**根拠**:
- 今回はクラブ経由ではなく個人契約のため
- 違反時に契約・関係性のリスクが大きい

**実装**:
- 撮影場所: 帝京大学（指導風景）/ 宿舎 / その他プロ感が出すぎない場所
- 表記: 「所属：トヨタヴェルブリッツ」の文字のみ
- エージェントに撮影現場同席を依頼検討

## 2026-04-28: 公開タイミング — 夏合宿シーズン狙い

**決定**: 7月下旬〜の夏合宿期間に合わせてコンテンツを順次公開。

**根拠**:
- 夏合宿の直前・期間中・直後は、食事に苦労した記憶が新しい時期
- メッセージの刺さりが最大化されるタイミング

**逆算スケジュール**:
- 5月中: 質問・絵コンテ確定
- 6月中: 撮影
- 7月上旬: 営業用チラシ完成
- 7月下旬〜: 順次公開
