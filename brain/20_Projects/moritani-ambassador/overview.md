# ゴール
ラグビー界に「アスリートの土台は食であり、投資しないと勝てない時代である」と認識を変えさせ、その解として **FAM/FAMBOX を提示** する。

# Why
- 守屋選手の **「身近で意識の高い強い選手」** という立ち位置（≠雲の上の代表選手）が、後輩・読者に **追体験させる導線** を作れる
- ラグビー界は他競技に比べて **食への意識・投資が遅れている** → 「フィジカル強化 → 栄養」の説得力ある語り手として最適
- FAM側が直接訴求するのではなく、**選手の口から語ってもらう** ことで第三者性を獲得

# 成功条件（Definition of Done）
- [ ] インタビュー記事を **夏合宿シーズン直前〜期間中** に公開できている
- [ ] SNSショート動画が並走で展開され、本編記事への流入動線になっている
- [ ] 営業用チラシ（7月上旬）が実営業活動に投入されている
- [ ] ラグビー界外（バスケ等）への横展開仮説が見えている

# マイルストーン
- [ ] **MS1: 5/8打ち合わせ** — 「言わせたい結論」確定 + 質問項目 + 絵コンテ案
- [ ] **MS2: 5月中** — 質問項目最終化、エージェント共有、事前打ち合わせ実施

# 主要な戦略判断（決まったこと）

## ターゲット選定の理由
**日本代表のトップ選手ではなく、「部活内で一目置かれる、身近で意識の高い強い選手」を起用**。20年の実体験を入り口に「ラグビー選手あるある」を提示し、読者に追体験させる。

## 撮影制約（重要）
- 個人契約（クラブ経由ではない）
- **トヨタヴェルブリッツのユニフォーム着用・チームロゴ使用は不可**
- 「所属：トヨタヴェルブリッツ」の **文字表記のみ** 可能
- 代替案：帝京大学での指導風景、宿舎での撮影 等で **プロ感が出すぎない形** に調整

## インタビュー設計の方針
**通常型（出てきた答えに任せる）ではなく、「言わせたいメッセージ」を先に決めて逆算設計**。
1. FAM側が「これだけは言わせたい」を決める
2. それに紐づくエピソードを守屋選手が持っているかを **事前ヒアリング**
3. 持っている → 言いやすい質問を本番用に設計
4. 持っていない → その質問は外す（無理に引き出さない）

# 公開タイミング戦略
**夏合宿の直前・期間中・直後** が最も効果的。食事が合わなくて苦労した記憶が残っている時期にメッセージが刺さる。

# 横展開の可能性
- **バスケットボール界**（Bリーグ西宮ストークス／現・神戸ストークス）
- 松浦さんの高校後輩経由で社長アプローチ可能
- 管理栄養士常駐チームでも「管理栄養士のサポートツール」として導入提案可能（三宅さん知見）
- 実績：アルバルク東京の管理栄養士に購入実績、他チーム資料請求あり
- ハードル：バスケ界の予算規模 → アウェー試合スポット導入も視野
