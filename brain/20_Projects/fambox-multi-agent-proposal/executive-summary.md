# FAMBOX マルチエージェント運営

## 次の一歩を、3秒で動かす。

---

## 構想

FAMBOXの運営を **5つのAIエージェント + 人間（FAMBOX運営チーム）の監督** によるマルチエージェント体制に進化させる。

人手で点と点を結ぶ速度が、いまのビジネスの上限を決めている。エージェントが判断と実行を担い、運営チームは **ガードレール設計と最終承認** に集中する構造へ突破する。

## なぜ「いま」か

| 指標 | 値 |
|---|---|
| Googleコードに占めるAI生成 | **50% → 75%**（半年で1.5倍） |
| AI活用による生産性向上 | **6倍** |
| ホルムズ海峡対応: 人 vs AI | **72時間 vs 3秒**（86,400倍） |

> 「ビジネスのスピードが、人間が手作業で点と点を結びつけるスピードによって上限設定されている」
> — Google Workspace VP ユリ・キム氏

## 5エージェントの役割

| エージェント | 動かす範囲 |
|---|---|
| **在庫モニター** | 仕入先API・倉庫データを24/7監視、入荷予測 |
| **栄養計算** | PFCバランス・カロリー・アレルギーを並列計算 |
| **顧客嗜好** | 個別の好み・継続パターンを学習し最適化 |
| **配送最適化** | ルート・冷蔵管理・配達タイミングを統合計算 |
| **異常検知 + 仮説** | 異常を検知し、原因仮説3つを自動提示 |

統合役の **オーケストレーター** が5つを束ね、人間が最終承認する。

## 致命的領域は必ず人間が握る

- アレルギー誤配送ゼロの確認
- 季節キャンペーン・新商品の方針判断
- 重大インシデント時のエスカレーション
- 顧客との直接対話（人間関係）

## Phase 1（最初の3ヶ月）：在庫モニターから始める

**目標**:
- 月間食材ロス: **-30%**
- 入荷遅延の検知時間: 24時間 → **1時間**
- 在庫確認作業: 週5時間 → **週1時間**

効果が見えやすく、致命的領域に踏み込まない領域から動かす。Phase 1で価値が見えてから、合意の上で次フェーズへ進む。

## 段階展開ロードマップ

| Phase | 期間 | 追加 |
|---|---|---|
| 1 | 0-3ヶ月 | 在庫モニター |
| 2 | 3-6ヶ月 | + 栄養計算 + 異常検知 |
| 3 | 6-9ヶ月 | + 顧客嗜好 + 配送最適化 |
| 4 | 9-12ヶ月 | + オーケストレーター統合 |

各フェーズ後に **降りる選択肢を残す** 段階設計。
