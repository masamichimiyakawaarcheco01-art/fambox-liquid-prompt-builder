# ROI 試算（年間）

## 前提

本資料は **構造的試算** であり、実数値は FAMBOX 側から提供いただいた後に確定します。
仮置きの数値は **架空値** であり、実際の数値に置き換える運用です。

## 効果領域（5カテゴリ）

### 1. 食材ロス削減（Phase 1 で実現）

| 項目 | 仮置き値 | 算出根拠 |
|---|---|---|
| 現在の月間食材ロス | ¥a 万 | FAMBOX実数値で確定 |
| 削減率（Phase 1 目標） | 30% | 在庫モニターによる早期検知・需要予測 |
| **年間削減効果** | **¥a × 0.3 × 12 万** | |

**根拠**:
- 仕入先APIから入荷予測を24/7行うため、過剰仕入れを回避
- 賞味期限切れ食材を優先消費するメニュー組み立て
- Manhattan Associates等の事例で類似効果が実証済

### 2. 機会損失回避（Phase 1 で部分実現、Phase 2 で本格化）

| 項目 | 仮置き値 | 算出根拠 |
|---|---|---|
| 現在の月間機会損失（在庫断絶・配送遅延） | ¥b 万 | FAMBOX実数値で確定 |
| 削減率 | 50% | 異常検知の早期化 |
| **年間効果** | **¥b × 0.5 × 12 万** | |

**根拠**:
- 食材断絶 → 代替メニュー自動生成（3秒以内）
- 異常検知エージェントが「失注前」に警告

### 3. 運営チームの時間削減

| 業務 | Before | After | 削減 |
|---|---|---|---|
| 在庫確認・発注業務 | 週 5時間 | 週 1時間 | 4時間/週 |
| メニュー組み立て | 週 8時間 | 週 2時間 | 6時間/週 |
| 異常対応の初動 | 週 3時間 | 週 0.5時間 | 2.5時間/週 |
| 配送調整 | 週 4時間 | 週 1時間 | 3時間/週 |
| **合計** | 週 20時間 | 週 4.5時間 | **15.5時間/週** |

**年間削減**: 15.5時間 × 52週 = **約 806時間/年**
時給換算（¥3,000 と仮置き）: **¥240万/年**

**戦略的価値**: 削減時間が **戦略・関係性・新規開拓** に再配分される。直接金銭換算以上の価値。

### 4. 個別最適化による継続率向上（Phase 3 で本格化）

| 項目 | 仮置き値 | 算出根拠 |
|---|---|---|
| 現在の月間継続率 | c% | FAMBOX実数値で確定 |
| Phase 3 後の継続率 | c% + 15ptp | 顧客嗜好エージェントによる個別最適化 |
| **年間LTV向上分** | **顧客数 × ARPU × 継続月数増加分** | |

**根拠**:
- 嗜好データに基づく個別メニュー
- 継続パターン異常の早期検知 → 離脱前介入

### 5. 異常検知の早期化（数値化困難・大）

| 項目 | 効果 |
|---|---|
| 大規模インシデント回避 | 食中毒・アレルギー誤配送等の致命的事故の早期検知 |
| ブランド毀損リスク低減 | SNS炎上・口コミ悪化の早期察知 |
| 経営判断の高速化 | 異常時に「原因仮説3つ + 検証手順」が即時提示 |

→ 直接金銭換算は困難だが、**インシデント1件あたり数百万〜数千万円のリスク回避** に相当。

| リスク | 緩和策 |
